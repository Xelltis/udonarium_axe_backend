# SkyWayのアプリを作る

SkyWay版のAxeは、参加者どうしのやりとりに[SkyWay](https://skyway.ntt.com/)を使います。
トークン発行サーバー（PHP版かVercel版）は、SkyWayの**アプリケーション**の**アプリケーションID**と**シークレットキー**を使って、Axeにトークンを渡します（→ [SkyWay版のしくみ](/skyway/)）。
このページは、そのアプリケーションを作り、2つの値を控えるまでの手順です。
かかる時間は10分ほどです。

<Journey mode="skyway" here="app" />

サーバー版（Cloudflare版と、Vercel版の部屋のサーバー）だけを使うなら、SkyWayのアプリは要りません。

## SkyWayの料金

SkyWayは、NTTドコモビジネスのサービスです。
新しく作ったプロジェクトは、**Freeプラン**（無料版）で始まります。
Freeプランには、1か月に使える量（部屋に入った回数、通信の量など）の上限があり、超えるとその月は使えなくなることがあります。
2026年10月の時点では、接続は1か月に50万回まで、TURNとSFUの通信はそれぞれ1か月に500GBまでです。
使える量と、使ってよい範囲は変わることがあるので、[SkyWayの料金のページ](https://skyway.ntt.com/ja/pricing/)で確かめてください。

## 1. SkyWayのアカウントを作る

すでにアカウントがあれば、[SkyWayのコンソール](https://console.skyway.ntt.com/login/)にログインして手順2に進みます。

1. [SkyWayのコンソールの登録ページ](https://console.skyway.ntt.com/signup)を開きます。「無料で始める」という見出しの画面です。
2. **メールアドレス**と、12文字以上の**パスワード**を入れます。
3. 利用規約とプライバシーポリシーに同意するチェックを入れ、**登録**を押します。
4. 「仮登録が完了しました」と出たら、メールを開きます。`noreply@skyway.ntt.com`から届いたメールの中のリンクを押すと、登録が終わります。メールが見当たらないときは、迷惑メールのフォルダも探してください。
5. [コンソールのログインの画面](https://console.skyway.ntt.com/login/)で、登録したメールアドレスとパスワードを入れてログインします。

ログインすると、「多要素認証のご案内」が出ることがあります。
多要素認証は、ログインのときに、パスワードのほかにスマートフォンでの確認を求めるしくみです。
設定しなくても先に進めます。
あとで設定するときは、**閉じる**を押します。

## 2. プロジェクトを作る

SkyWayでは、アプリケーションを**プロジェクト**にまとめて置きます。
はじめてログインしたときにプロジェクトが無ければ、1つ作ります。
プロジェクトが1つも無いときは、「作成済みのプロジェクトはありません。」と出ます。

1. 画面の上の、プロジェクトを切り替えるところを開き、**プロジェクトを作成**を選びます。
2. 「新しいプロジェクトを作成する」の画面で、**プロジェクト名**に名前（例：`udonarium-axe`）を入れます。32文字まで入れられます。
3. **OK**を押します。名前は、あとから変えられます。

作ったプロジェクトは、Freeプランで始まります。

## 3. アプリケーションを作る

1. 左のメニューの**アプリケーション一覧**を開きます。
2. 右上の**アプリケーションを作成**を押します。
3. 「アプリケーション作成」の画面で、**アプリケーション名**に名前（例：`my-axe`）を入れ、**作成**を押します。
4. アプリケーション一覧に戻り、「アプリケーションを作成しました」と出れば、できています。

アプリケーションを作れるのは、プロジェクトのオーナーと管理者です。
自分で作ったプロジェクトなら、自分がオーナーなので作れます。

身内用と公開用など、トークン発行サーバーを2つ以上置くときは、アプリケーションもそれぞれに作っておくと、使った量を分けて見られます。

## 4. アプリケーションIDとシークレットキーを控える

**アプリケーション一覧**に、作ったアプリケーションが1枚のカードとして出ます。
カードには、**アプリケーションID**と**シークレットキー**が並んでいます。

1. アプリケーションIDをコピーして、控えます。
2. シークレットキーは、伏せて表示されています。横のコピーのボタンを押すと、伏せたままコピーできます。「コピーしました」と出たら、控えに貼り付けます。中身を目で確かめたいときは、目の形のボタンを押すと表示されます。

シークレットキーは、あとからも同じカードか、アプリケーションの**詳細**の画面で見られます。

控えた2つは、トークン発行サーバーの設定に入れます。

| トークン発行サーバーの設定の名前 | 入れるもの         |
| -------------------------------- | ------------------ |
| `SKYWAY_APP_ID`                  | アプリケーションID |
| `SKYWAY_SECRET`                  | シークレットキー   |

::: warning シークレットキーは人に見せない
シークレットキーを知っている人は、あなたのSkyWayのアプリケーションのトークンを作れます。
そうなると、あなたのFreeプランの量を、知らない人に使われてしまいます。
チャットやSNS、スクリーンショットには載せないでください（→ [設置の準備](/guide/prepare#秘密の値の扱い)）。
漏れたかもしれないときは、作り直します。
アプリケーションの**詳細**を開き、シークレットキーの**再生成**を押して、確かめる画面でもう一度**再生成**を押します。
作り直すと、前のシークレットキーは二度と使えなくなるので、トークン発行サーバーの設定も新しいものに入れ替えます。
:::
