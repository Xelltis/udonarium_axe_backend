# SkyWayのアプリを作る

SkyWay版のAxeは、参加者どうしのやりとりに[SkyWay](https://skyway.ntt.com/)を使います。
トークン発行サーバー（PHP版かVercel版）は、SkyWayの**アプリケーション**の**アプリケーションID**と**シークレットキー**を使って、Axeにトークンを渡します（→ [SkyWay版のしくみ](/skyway/)）。
このページは、そのアプリケーションを作り、2つの値を控えるまでの手順です。
かかる時間は10分ほどです。

サーバー版（Cloudflare版と、Vercel版の部屋のサーバー）だけを使うなら、SkyWayのアプリは要りません。

## SkyWayの料金

SkyWayは、NTTドコモビジネスのサービスです。
新しく作ったプロジェクトは、**Freeプラン**（無料版）で始まります。
Freeプランには、1か月に使える量（部屋に入った回数、通信の量など）の上限があり、超えるとその月は使えなくなることがあります。
使える量と、使ってよい範囲は変わることがあるので、[SkyWayの料金のページ](https://skyway.ntt.com/ja/pricing/)で確かめてください。

## 1. SkyWayのアカウントを作る

すでにアカウントがあれば、[SkyWayのコンソール](https://console.skyway.ntt.com/login/)にログインして手順2に進みます。

1. [SkyWayのコンソールの登録ページ](https://console.skyway.ntt.com/signup)を開きます。
2. 画面の案内に従って、メールアドレスなどを入れて登録します。
3. 登録が終わったら、コンソールにログインします。

## 2. プロジェクトを作る

SkyWayでは、アプリケーションを**プロジェクト**にまとめて置きます。
はじめてログインしたときにプロジェクトが無ければ、1つ作ります。

1. 画面の上の、プロジェクトを切り替えるところを開き、**プロジェクトを作成**を選びます。
2. **プロジェクト名**に名前（例：`udonarium-axe`）を入れ、**作成**を押します。名前は、あとから変えられます。

## 3. アプリケーションを作る

1. 左のメニューの**アプリケーション一覧**を開きます。
2. 右上の**アプリケーションを作成**を押します。
3. アプリケーションの名前（例：`my-axe`）を入れ、**作成**を押します。

身内用と公開用など、トークン発行サーバーを2つ以上置くときは、アプリケーションもそれぞれに作っておくと、使った量を分けて見られます。

## 4. アプリケーションIDとシークレットキーを控える

**アプリケーション一覧**に、作ったアプリケーションが出ます。
そこに**アプリケーションID**と**シークレットキー**が並んでいるので、それぞれコピーして控えます。

控えた2つは、トークン発行サーバーの設定に入れます。

| トークン発行サーバーの設定の名前 | 入れるもの         |
| -------------------------------- | ------------------ |
| `SKYWAY_APP_ID`                  | アプリケーションID |
| `SKYWAY_SECRET`                  | シークレットキー   |

::: warning シークレットキーは人に見せない
シークレットキーを知っている人は、あなたのSkyWayのアプリケーションのトークンを作れます。
そうなると、あなたのFreeプランの量を、知らない人に使われてしまいます。
チャットやSNS、スクリーンショットには載せないでください（→ [設置の準備](/guide/prepare#秘密の値の扱い)）。
漏れたかもしれないときは、コンソールでシークレットキーを作り直し、トークン発行サーバーの設定も入れ替えます。
:::
