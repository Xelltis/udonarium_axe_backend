# SkyWay版で困ったとき

トークン発行サーバー（PHP版・Vercel版・Cloudflare版）で、よくあるつまずきと、その直しかたをまとめました。
まずブラウザで、トークン発行サーバーのURLの後ろに`/v1/status`を付けたものを開き、何が出るかを見てください（例：`https://example.com/backend/v1/status`）。

## `/v1/status`の結果から探す

| 出たもの                                            | 意味と、見るところ                                                                                                          |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `OK`                                                | PHP版が正しく動いています。[Axeからつながらない](#axeからつながらない)へ                                                    |
| `ORIGIN_REQUIRED`を含む文字                         | Vercel版が正しく動いています（ブラウザで直接開くとOriginが付かないので断る）。[Axeからつながらない](#axeからつながらない)へ |
| `CONFIG_INVALID`を含む文字                          | Vercel版の環境変数が足りないか、形が違います。[Vercel版の設定が読めない](#vercel版の設定が読めない)へ                       |
| 真っ白、または「500 Internal Server Error」         | PHP版の`.env`が読めないか、PHPが古い。[PHP版で500になる](#php版で500になる)へ                                               |
| 「404 Not Found」（サーバーの画面）、ファイルの一覧 | PHP版で`.htaccess`が効いていないか、置き場所が違う。[PHP版で404になる](#php版で404になる)へ                                 |
| `{"error":"Origin is required."}`                   | PHP版で、URLの綴りが違う（`/v1/status`のほかのURLは、ブラウザで開くとこう返る）                                             |

## PHP版で500になる

1. **`.env`があるか**：FileZillaなどで隠しファイルを表示して、`index.php`と同じフォルダに`.env`があるかを確かめます（→ [レンタルサーバーに置く](/skyway/php#隠しファイルを表示する)）。
2. **名前が正しいか**：`.env.txt`や`env`になっていないかを見ます。
3. **必須の値があるか**：`SKYWAY_APP_ID`と`SKYWAY_SECRET`が空でないかを確かめます。
4. **`SKYWAY_UDONARIUM_LOBBY_SIZE`が1以上の整数か**：`3`のように数字だけを書きます。
5. **PHPの版が8.3以上か**：管理画面でPHPの版を確かめます。8.2以前ではエラーになります。
6. **エラーログ**：レンタルサーバーの管理画面から、PHPのエラーログを見ます。`No .env file found`や`SKYWAY_APP_ID is required`のように、原因が書いてあります。

## PHP版で404になる

1. **`.htaccess`が上がっているか**：隠しファイルを表示して確かめます。
2. **`.htaccess`が効くサーバーか**：`mod_rewrite`と、`.htaccess`での設定（`AllowOverride`）が許されている必要があります。サーバーの説明書で確かめてください。
3. **置き場所**：`index.php`が、開いているURLのフォルダの直下にあるかを確かめます。フォルダごとアップロードして、1段深くなっていることがよくあります。

::: warning `.htaccess`が使えないサーバーでは使わないでください
`.htaccess`が効かないと、`.env`がWebから読めてしまうおそれがあります。
その場合は、PHP版ではなく[Vercel](/skyway/vercel)を使ってください。
:::

## Vercel版の設定が読めない

`CONFIG_INVALID`のときは、環境変数が足りないか、値の形が違います。

1. プロジェクトの**Environment Variables**で、`SKYWAY_APP_ID`、`SKYWAY_SECRET`、`ACCESS_CONTROL_ALLOW_ORIGIN`があるかを確かめます。
2. `SKYWAY_TOKEN_TTL_SECONDS`を入れたなら、`60`〜`604800`の数字かを確かめます。
3. 直したら、**Redeploy**します。環境変数を変えても、いま動いているデプロイには反映されません（→ [Vercelに置く](/skyway/vercel#設定を直す)）。

原因は、プロジェクトの**Logs**にも出ます。

## Axeからつながらない

`/v1/status`は正しいのに、Axeで部屋に入れないときです。
Axeを開いたブラウザで開発者ツールを開き、**コンソール**と**ネットワーク**を見ます（→ [設置の準備](/guide/prepare#開発者ツールを開く)）。

| 見えるもの                                                 | 原因と直しかた                                                                                                        |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| CORSのエラー（`Access-Control-Allow-Origin`が無い、違う）  | `ACCESS_CONTROL_ALLOW_ORIGIN`が、Axeを開いているページのOriginと一致していない。PHP版では末尾の`/`も確かめる          |
| `403`（PHP版は`Forbidden.`、Vercel版とCloudflare版は`ORIGIN_FORBIDDEN`） | 上と同じ。許可していないOriginから来ている                                                                            |
| 混在コンテンツ（Mixed Content）のエラー                    | Axeが`https://`なのに、`backend.url`が`http://`になっている                                                           |
| リクエストが飛んでいない                                   | Axeの`assets/config.json`の`backend.url`が空か、間違っている                                                          |
| `404`                                                      | `backend.url`にパスが余分に付いている（例：`.../v1`まで書いている）か、足りない（サブディレクトリの名前が抜けている） |

## ときどき最初の1回だけ失敗する（Vercel版）

しばらく使われていないと、Vercelの関数は眠った状態になり、最初の1回の応答に時間がかかることがあります（コールドスタート）。
Axeは、つながらないときや一時的なエラーのときに、間を置いて何度か試し直します。
たいていは試し直しで通るので、気にしなくて構いません。

## トークンは返るのにSkyWayにつながらない

- **アプリケーションIDとシークレットキーの組み合わせ**：別のアプリケーションのシークレットキーを入れていると、署名が合わずにSkyWayが断ります。SkyWayのコンソールで、同じアプリケーションのIDとキーかを確かめます。
- **値の前後の空白**：値を貼るとき、前後に空白や改行が入っていないかを確かめます。
- **PHP版の値の中の`;`**：値を`"`で囲まずに書くと、`;`から後ろが切り捨てられます。`.env`で`"`で囲みます。
- **PHP版のサーバーの時計**：トークンには発行時刻と期限が入っています。サーバーの時計が大きくずれていると、SkyWayが期限切れと判断することがあります。

## それでも解決しないとき

[Issues](https://github.com/Xelltis/udonarium_axe_backend/issues)で知らせてください。
使っている版（PHP版ならレンタルサーバーの名前とPHPの版）、`/v1/status`の結果、開発者ツールに出たエラーを書いてもらえると助かります。
`.env`や環境変数の値（特にシークレットキー）は貼らないでください。
