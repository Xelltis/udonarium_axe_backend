# Vercel版で困ったとき

よくあるつまずきと、その直しかたをまとめました。
Vercel版のエラーは`{"error": {"code": "...", "message": "..."}}`の形で返るので、まず`code`を見てください。

## エラーのコードから探す

| コード              | よくある原因                                               | 直しかた                                                                |
| ------------------- | ---------------------------------------------------------- | ----------------------------------------------------------------------- |
| `ORIGIN_REQUIRED`   | ブラウザのアドレスバーや、`Origin`を付けない`curl`で開いた | `curl -H "Origin: https://axe.example.com" ...`のように`Origin`を付ける |
| `ORIGIN_FORBIDDEN`  | `ACCESS_CONTROL_ALLOW_ORIGIN`とAxeのOriginが一致していない | `https://`か`http://`か、ポート、`www`の有無まで合わせる                |
| `CONFIG_INVALID`    | 環境変数が足りない、または値の形が違う                     | [設定項目](/vercel/configuration)を見直し、変えたら**Redeploy**する     |
| `VALIDATION_FAILED` | トークンを頼む本文の形が違う                               | `Content-Type: application/json`と、`formatVersion`が`1`かを確かめる    |
| `INTERNAL_ERROR`    | 想定していない失敗                                         | Vercelの「Logs」で原因を見る                                            |

## 環境変数を変えたのに直らない

Vercelでは、環境変数を変えても、すでに動いているデプロイには反映されません。
「Deployments」から最新のデプロイを選び、**Redeploy**を押してください。

## ときどき最初の1回だけ失敗する

しばらく使われていないと、Vercelの関数は眠った状態になり、最初の1回の応答に時間がかかることがあります（コールドスタート）。
Axeは、つながらないときや一時的なエラーのときに、間を置いて何度か試し直します。
たいていは試し直しで通るので、気にしなくて構いません。

## Axeからつながらない

Axeを開いたブラウザで開発者ツール（F12）を開き、「コンソール」と「ネットワーク」を見ます。

| 見えるもの                                          | 原因と直しかた                                                      |
| --------------------------------------------------- | ------------------------------------------------------------------- |
| CORSのエラー（`Access-Control-Allow-Origin`が無い） | `ACCESS_CONTROL_ALLOW_ORIGIN`がAxeのOriginと一致していない          |
| 混在コンテンツ（Mixed Content）のエラー             | Axeが`https://`なのに、`backend.url`が`http://`になっている         |
| リクエストが飛んでいない                            | Axeの`assets/config.json`の`backend.url`が空か、間違っている        |
| `404`                                               | `backend.url`にパスが余分に付いている（例：`.../v1`まで書いている） |

## トークンは返るのにSkyWayにつながらない

- **アプリIDとシークレットキーの組み合わせ。** 別のアプリのシークレットキーを入れていると、署名が合わずにSkyWayが断ります。
- **前後の空白。** 環境変数に値を貼るとき、前後に空白や改行が入っていないかを確かめます。

## それでも解決しないとき

[Issues](https://github.com/Xelltis/udonarium_axe_backend/issues)で知らせてください。
エラーの`code`と`message`、Vercelの「Logs」に出たエラーを書いてもらえると助かります。
環境変数の値（特にシークレットキー）は貼らないでください。
