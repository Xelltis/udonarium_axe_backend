# よくある質問

バックエンド全体に関わる質問をまとめました。
それぞれのアプリに固有の困りごとは、各アプリの「困ったとき」を見てください。

## 設置について

### バックエンドはいくつ要りますか？

いまのSkyWay版なら、トークン発行サーバー（PHP版かVercel版）が1つあれば遊べます。
アセットサーバー（Cloudflare版）は、なくても構いません。
詳しくは[どれを使うか](/guide/choose)を見てください。

### SkyWayなしで遊べますか？

いまはできません。
SkyWayを使わずに遊べる**サーバー版**を作っているところです。
部屋のサーバーはCloudflare版のWorkerに入っていて、Axe側の対応ができれば、SkyWayのアプリもトークン発行サーバーも要らなくなります。
進み具合は[今後の計画](/guide/roadmap)にあります。

### 本家のユドナリウムでも使えますか？

トークン発行サーバー（PHP版・Vercel版）は、本家ユドナリウムが呼び出すAPI（`POST /v1/skyway2023/token`）にも対応しているので使えます。
アセットサーバー（Cloudflare版）は、Axe専用です。本家ユドナリウムからは使われません。

### お金はかかりますか？

ふつうの使いかたなら、無料枠の範囲に収まることがほとんどです。

- **PHP版**：契約中のレンタルサーバーで動かすなら、追加の費用はありません。
- **Vercel版**：Vercelの無料プラン（Hobby）で足ります。Hobbyは個人の非商用の利用が前提です。
- **Cloudflare版**：R2とWorkersの無料枠に収まることが多いです。目安は[運用と料金](/cloudflare/operations)にあります。
- **SkyWay**：SkyWayの料金体系に従います。最新の情報は[SkyWayの公式サイト](https://skyway.ntt.com/)で確かめてください。

### 身内用と公開用で分けられますか？

分けられます。
トークン発行サーバーもアセットサーバーも、名前を変えればいくつでも置けます。
Cloudflare版は、同じCloudflareアカウントに複数置いても、R2のバケットとレート制限はWorkerごとに分かれます。

## Originについて

### `ACCESS_CONTROL_ALLOW_ORIGIN`には何を書けばいいですか？

Axeを配信しているページのOriginです。
ブラウザのアドレスバーに出るURLのうち、`https://`からホスト名（とポート）までを書きます。

| アドレスバーのURL                | 書く値                    |
| -------------------------------- | ------------------------- |
| `https://axe.example.com/`       | `https://axe.example.com` |
| `https://example.com/udonarium/` | `https://example.com`     |
| `http://localhost:4200/`         | `http://localhost:4200`   |

複数あるときはカンマで区切ります（例：`https://axe.example.com,https://www.axe.example.com`）。

### 末尾に`/`を付けてもいいですか？

付けないでください。
サーバーによっては、書いた文字列をそのままブラウザに返すため、`https://axe.example.com/`と書くとブラウザが「Originが違う」と判断して通信を止めます。

### `*`（すべて許可）にしてもいいですか？

試すときだけにしてください。
`*`にすると、ほかのサイトに置かれたAxeからも、あなたのSkyWayアプリのトークンを使えてしまいます。
SkyWayの利用量はあなたの契約に数えられるので、本番では必ず具体的なOriginを書いてください。

## アセットサーバーについて

### アセットサーバーを止めたら、遊べなくなりますか？

遊べます。
アセットサーバーにつながらないときや、置かれていない画像は、これまでどおりP2Pで配られます。
`config.json`の`assets.url`を空にすれば、アセットサーバーを使わなくなります。

### 置いた画像は、ほかの人に見られますか？

画像と音声は、中身のSHA-256を名前にして置いています。
名前を知っていれば誰でも読めますが、名前は中身から計算されるので、中身を持っていない人には推測できません。
メンバー以外から完全に隠したい素材があるときは、[安全のしくみ](/cloudflare/security)を読んだうえで判断してください。

### 誰でも画像を上げられてしまいませんか？

アップロードを受けるのは、`ACCESS_CONTROL_ALLOW_ORIGIN`に書いたOriginのページからだけです。
ただし、Originはブラウザ以外からなら偽れるので、これは乱用を抑えるための制限で、置ける人を限るものではありません。
送信元ごとの上限と、30日の保持期間で、置かれる量を抑えています。
ログインした人だけが置けるようにするのは、サーバー版の部屋ができてからです。

### 画像はいつまで残りますか？

既定では、置いてから30日です（`ASSET_RETENTION_DAYS`で変えられます）。
期限を過ぎた画像は、GMが次に部屋を読み込んだときに、自動でまた上がります。

## そのほか

### 脆弱性を見つけました

公開のIssueには書かず、[GitHub Security Advisory](https://github.com/Xelltis/udonarium_axe_backend/security/advisories/new)から非公開で知らせてください。
5営業日以内に返答します。

### 機能の要望や不具合の報告はどこへ？

[Issues](https://github.com/Xelltis/udonarium_axe_backend/issues)へどうぞ。
Axe本体についての要望は、[Axeのリポジトリ](https://github.com/Xelltis/udonarium_axe/issues)へお願いします。
