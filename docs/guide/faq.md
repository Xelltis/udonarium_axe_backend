# よくある質問

ここに無い困りごとは、[SkyWay版で困ったとき](/skyway/troubleshooting)と[サーバー版で困ったとき](/server/troubleshooting)を見てください。

## 置くこと

### サーバーはいくつ要りますか？

1つです。
SkyWay版ならトークン発行サーバー（PHP版かVercel版）を、サーバー版なら部屋のサーバー（Cloudflare版かVercel版）を1つ置きます。
両方の方式で配信したいときは、Vercel版を1つ置いて、両方の設定を入れることもできます（→ [どれを置くか](/guide/choose)）。

### SkyWayなしで遊べますか？

サーバー版で遊べます。
部屋のサーバーを置き、Axeの`config.json`で`transport`を`"server"`にします（→ [Axeの設定](/guide/client-config#サーバー版のとき)）。
SkyWayのアプリも、トークン発行サーバーも要りません。

### 本家のユドナリウムでも使えますか？

トークン発行サーバー（PHP版・Vercel版）は、本家ユドナリウムが呼ぶAPI（`POST /v1/skyway2023/token`）にも対応しているので使えます。
部屋のサーバーはAxe専用で、本家ユドナリウムからは使えません。

### お金はかかりますか？

ふつうの使いかたなら、無料の範囲に収まることがほとんどです。

- **PHP版**：契約中のレンタルサーバーで動かすなら、追加の費用はありません。
- **Vercel版**：Vercelは無料のプラン（Hobby）で足ります。Hobbyは個人の非商用の利用が前提です。部屋のサーバーを置くときに使うRedis（UpstashのFree）は、1か月に使えるコマンドの数で足りなくなることがあります（→ [費用と上限](/operate/costs#vercel版)）。
- **Cloudflare版**：無料のプランで、1日に25卓ほどが目安です。それより多く遊ぶなら、有料のプラン（月$5）にします（→ [費用と上限](/operate/costs)）。
- **SkyWay**：新しいプロジェクトはFreeプラン（無料版）で始まります（→ [SkyWayのアプリを作る](/skyway/app#skywayの料金)）。

### 身内用と公開用で分けられますか？

分けられます。
どのサーバーも、名前を変えればいくつでも置けます。

## Originについて

### `ACCESS_CONTROL_ALLOW_ORIGIN`には何を書けばいいですか？

Axeを開いたときのURLのうち、`https://`からホスト名（とポート）までです。
例と書きかたは、[設置の準備](/guide/prepare#axeのoriginを確かめる)にあります。

### `*`（すべて許可）にしてもいいですか？

試すときだけにしてください。
SkyWay版では、ほかのサイトに置かれたAxeからも、あなたのSkyWayのアプリケーションが使えてしまいます。
サーバー版では、`*`だけにするとログインが通らず、部屋も作れません（→ [サーバー版の設定項目](/server/configuration#access-control-allow-origin)）。

## 画像と音声について

### SkyWay版で、画像と音声のためのサーバーは要りますか？

要りません。
SkyWay版では、画像と音声は参加者どうしのP2Pで配ります。

### サーバー版で置いた画像は、ほかの人に見られますか？

読めるのは、その部屋の席（GM・PL・見学）だけです。
ただし、パスワードの無い部屋には、だれでも見学として入れ、その部屋の画像と音声も読めます。
メンバー以外に見せたくない部屋には、パスワードを付けてください（→ [安全のしくみ](/operate/security#部屋の鍵を知っていれば入れる)）。

### サーバー版で、誰でも画像を上げられてしまいませんか？

上げられるのは、部屋にGMかPLとして入っている人だけです。
GMとPLは、Discordでログインして入ります。
見学の人は、受け取ることはできても、上げることはできません。

### サーバー版の画像は、いつまで残りますか？

部屋と一緒に消えます（→ [部屋が消えるとき](/server/#部屋が消えるとき)）。
保存しておいた部屋のデータを新しい部屋で読み込めば、画像と音声は、またその部屋に上がります。

## そのほか

### 脆弱性を見つけました

公開のIssueには書かず、[GitHub Security Advisory](https://github.com/Xelltis/udonarium_axe_backend/security/advisories/new)から非公開で知らせてください。
5営業日以内に返答します。

### 機能の要望や不具合の報告はどこへ？

[Issues](https://github.com/Xelltis/udonarium_axe_backend/issues)へどうぞ。
Axe本体についての要望は、[Axeのリポジトリ](https://github.com/Xelltis/udonarium_axe/issues)へお願いします。
