# はじめに

Udonarium Axe（以下Axe）は、HTMLとJavaScriptだけでできた静的なWebアプリです。
S3やGitHub Pages、レンタルサーバーの公開フォルダなど、ファイルを置ける場所ならどこでも配信できます。
ただし、参加者どうしをつなぐには、Axeの外にサーバーが要ります。
このドキュメントは、そのサーバーを置いて運営するためのものです。

## 2つの方式

Axeの配信には、2つの方式があります。
どちらで配信するかは、配信ごとにAxeの`config.json`で選びます（→ [Axeの設定](/guide/client-config)）。

| 方式       | つながりかた                                                                 | 置くサーバー                                         |
| ---------- | ---------------------------------------------------------------------------- | ---------------------------------------------------- |
| SkyWay版   | 参加者どうしが[SkyWay](https://skyway.ntt.com/)で直接つながる（P2P）。画像と音声もP2Pで配る | トークン発行サーバー（PHP版かVercel版）       |
| サーバー版 | 全員が部屋のサーバーにつながる。部屋のサーバーが卓の状態と画像と音声を持つ   | 部屋のサーバー（Cloudflare版かVercel版）             |

```text
SkyWay版
  Axe ─①トークンをもらう─▶ トークン発行サーバー（PHP版かVercel版）
  Axe ─②参加者どうしで直接やりとり─▶ SkyWay

サーバー版
  Axe ─ログイン、部屋、画像と音声、WebSocket─▶ 部屋のサーバー（Cloudflare版かVercel版）
```

サーバー版はAxe v1.68.0から使え、次のこともできます。

- 全員が抜けても、しばらくのあいだ卓が残る
- 裏向きのカードや秘話を、見てはいけない人の画面に届けない
- GMとPLはDiscordでログインして入り、ログインしていない人は見学だけにする
- 画像と音声を部屋ごとに預かり、その部屋の参加者にだけ配る

SkyWay版は、サーバー版ができたあとも残ります。
どちらにするかは、[どれを置くか](/guide/choose)で選べます。

## このリポジトリに入っているもの

| ディレクトリ      | 中身                                                                     | 動かす場所                                         |
| ----------------- | ------------------------------------------------------------------------ | -------------------------------------------------- |
| `apps/php`        | PHP版。SkyWay版のトークン発行サーバー                                    | レンタルサーバー（Apache＋PHP 8.3〜）              |
| `apps/vercel`     | Vercel版。SkyWay版のトークン発行サーバーと、サーバー版の部屋のサーバー   | Vercel Functions（Node.js 24）＋Redis＋Vercel Blob |
| `apps/cloudflare` | Cloudflare版。サーバー版の部屋のサーバー                                 | Cloudflare Workers＋Durable Objects＋R2            |
| `docs`            | このドキュメント（VitePress）                                            | GitHub Pages                                       |

PHP版には、部屋のサーバーはありません。
レンタルサーバーのPHPは、WebSocketをつなぎっぱなしにできないためです。

## 用語

| 用語                 | 意味                                                                                                     |
| -------------------- | -------------------------------------------------------------------------------------------------------- |
| トークン発行サーバー | SkyWay版で、AxeにSkyWayの認証トークンを作って渡すサーバー。PHP版かVercel版                               |
| 部屋のサーバー       | サーバー版で、参加者がつながる先。部屋ごとに卓の状態を持つ。Cloudflare版かVercel版                       |
| 部屋のアセット       | サーバー版で、部屋のサーバーが部屋ごとに預かる画像と音声                                                 |
| 席                   | 部屋に入っている1人ぶんの場所。役割（GM・PL・見学）を持つ                                                |
| Origin（オリジン）   | Webページの出どころ。`https://axe.example.com`のように、スキーム・ホスト名・ポートの組で、パスは含まない |
| CORS                 | ほかのOriginのページからのリクエストを受けるかどうかを、サーバーがブラウザに伝えるしくみ                 |
| JWT                  | 署名付きの小さなデータ。SkyWayのトークンや、ログインのトークンはJWTの形をしている                        |
| Worker               | Cloudflareの上で動く小さなプログラム。Cloudflare版はWorker                                               |
| R2                   | Cloudflareのファイル置き場。取り出すときの転送料がかからない                                             |
| Durable Objects      | Cloudflareの、状態を持てるWorker。Cloudflare版では部屋ごとに1つ置く                                      |
