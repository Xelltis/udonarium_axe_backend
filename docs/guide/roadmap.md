# 今後の計画（サーバー版）

Axeは、SkyWayを使わずに遊べる**サーバー版**の配信を作っています。
このページでは、そのねらいと決めたこと、どこまで進んだかを説明します。
内容は2026年10月時点のものです。

## なぜサーバー版を作るのか

SkyWay版では、参加者全員がたがいに直接つながり（フルメッシュ）、卓の状態をそれぞれのブラウザが持っています。
この形には、次のような限りがあります。

- 画像や音声を、持っている人が参加者1人ずつに送るので、人数が増えるほど回線を使う
- 裏向きのカードや秘話も、データとしては全員のブラウザに届いている
- 全員が抜けると、卓の状態はどこにも残らない
- 通信の品質を、まとめて測る場所がない

サーバー版では、部屋ごとのサーバーが卓の状態を持ち、参加者はそこにつながります。
サーバーが中継役になるので、見せてはいけないものを届けないことや、全員が抜けたあとに卓を残すことができるようになります。

## 決めたこと

| 項目           | 決めたこと                                                                                                        |
| -------------- | ----------------------------------------------------------------------------------------------------------------- |
| 動かす場所     | Cloudflare Workers＋Durable Objects（1部屋に1つ、部屋の一覧に1つ、ログインした人ごとに1つ）＋R2（画像と音声）     |
| コードの置き場 | このリポジトリの`apps/cloudflare`。いまのアセットサーバーに足していく                                             |
| SkyWay         | なくさない。SkyWay版とサーバー版のどちらで配信するかは、配信ごとに`config.json`で選ぶ（部屋ごとには切り替えない） |
| 卓の保持       | 最後の1人が抜けてから24時間で消す                                                                                 |
| 画像と音声     | アップロードから30日で消す（使われればまた上がる）。日数は設定で変えられる                                        |
| 本人確認       | 外部のアカウントでログインする（まずDiscord）。サーバー版の部屋では、GMとPLはログインが要り、匿名の人は見学だけ   |
| やらないこと   | 音声通話と映像、WebTransport、霧と視界をサーバーで計算すること                                                    |

## 進め方

| 段階    | 内容                                                                                             | 状況                                   |
| ------- | ------------------------------------------------------------------------------------------------ | -------------------------------------- |
| Phase 0 | 技術の下調べ。BCDiceがWorkerで動くか、Durable Objectsがどうふるまうか、データの大きさ            | 手元での確認は済み。本番での計測が残り |
| Phase 1 | バックエンドを1つのリポジトリにまとめる（PHP版・Vercel版・Cloudflare版）                         | 済み                                   |
| Phase 2 | 画像と音声をHTTPで配る（アセットサーバー）。SkyWay版の配信でも使える                             | 済み                                   |
| Phase 3 | 部屋のサーバー。卓の状態の同期だけを受け持ち、まずはベータ配信で試す                             | 済み（Axe v1.68.0から。ベータ）        |
| Phase 4 | Discordでのログインと、サーバーが保証する役割（GM・PL・見学）                                    | 済み（Axe v1.68.0から。ベータ）        |
| Phase 5 | 見てはいけない情報を届けない（裏向きのカード、秘話、シークレットダイス）。サーバーでダイスを振る | 済み（Axe v1.68.0から。ベータ）        |
| Phase 6 | 公開と運用。公式配信の切り替えを決め、セルフホストの手順と利用ガイドを整える                     | これから                               |

## セルフホストする人への影響

- **SkyWay版**は、これまでどおり使えます。PHP版かVercel版のトークン発行サーバーがあれば遊べます。
- **アセットサーバー**（Cloudflare版）は、いまからSkyWay版の配信に足せます。
- **サーバー版**をセルフホストするには、Cloudflareのアカウント（Workers、Durable Objects、R2）と、ログインに使うDiscordのアプリの登録が要ります。Durable Objectsは、Cloudflare版をデプロイすると一緒に作られます。D1は使いません。手順は[デプロイする](/cloudflare/deploy)と[ログインと役割](/cloudflare/login)にあります。

## 費用の見込み

料金は2026年10月時点のもので、Phase 0の計測で実測値に置き換える予定です。

- 6人で4時間の卓では、遊んでいるあいだ部屋のサーバーはずっと動いています。
- Cloudflareの無料枠では、1日に5〜7卓ほどが目安です。
- 有料プラン（月5ドル）では、月に約220卓が込みの範囲に入り、超えた分は1卓あたり約0.05ドルです。
- 画像と音声の置き場（R2）は、取り出すときの転送料がかかりません。

いまのアセットサーバーの料金の目安は、[運用と料金](/cloudflare/operations)にあります。
