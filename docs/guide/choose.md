# どれを置くか

置くサーバーは、2つのことを順に決めると選べます。
まず方式（SkyWay版かサーバー版か）を選び、次にその方式のサーバーをどこで動かすかを選びます。

## 1. 方式を選ぶ

|                      | SkyWay版                                   | サーバー版                                                           |
| -------------------- | ------------------------------------------ | -------------------------------------------------------------------- |
| つながりかた         | 参加者どうしが直接つながる（P2P）          | 全員が部屋のサーバーにつながる                                       |
| 卓の状態を持つ場所   | 参加者のブラウザだけ                       | 部屋のサーバーと、参加者のブラウザ                                   |
| 全員が抜けたとき     | 卓の状態は消える                           | 部屋のサーバーにしばらく残る（既定24時間）                           |
| 画像と音声           | 持っている人から参加者どうしで配る         | 部屋のサーバーが部屋ごとに預かって配る                               |
| 見えない情報         | 裏向きのカードの表や秘話も、データとしては全員に届く | 見てはいけない人には届けない                               |
| 入る人               | だれでも同じように入る                     | GMとPLはDiscordでログインし、ログインしていない人は見学              |
| 要るアカウント       | SkyWay                                     | Discord（ログインに使うアプリを作るため）                            |
| 使えるAxe            | どの版でも                                 | v1.68.0から                                                          |

迷ったら、すぐに試せる**SkyWay版**から始めてください。
裏向きのカードや秘話を確実に隠したいとき、全員が抜けても卓を残したいときは、**サーバー版**が向きます。

## 2. 置き場所を選ぶ

### SkyWay版：PHP版かVercel版か

トークン発行サーバーは、PHP版かVercel版のどちらか1つを置きます。
どちらも、Axeから見て同じように動きます。

|                    | PHP版                                           | Vercel版                                      |
| ------------------ | ----------------------------------------------- | --------------------------------------------- |
| 動かす場所         | 借りているレンタルサーバー（Apache＋PHP 8.3〜） | Vercel（東京のリージョン）                    |
| 費用               | 契約中のサーバーがあれば追加はなし              | Vercelの無料のプラン（Hobby）で足りる         |
| 設置のしかた       | zipを展開してFTPで置き、`.env`を書く            | Deployボタンを押して環境変数を入れる          |
| トークンの有効期間 | 24時間（固定）                                  | 既定24時間。60秒〜7日の間で変えられる         |
| 向いている人       | すでにレンタルサーバーを借りている人            | サーバーを持っていない人、手早く済ませたい人  |

迷ったら、**Vercel版**がいちばん手軽です。
Vercelの無料のプランは、個人の非商用での利用が前提です。

::: tip 本家のバックエンドも使えます
本家ユドナリウムの[udonarium-backend](https://github.com/TK11235/udonarium-backend)も、Axeが呼ぶAPI（`GET /v1/status`と`POST /v1/skyway2023/token`）に対応しているので、そのまま使えます。
:::

### サーバー版：Cloudflare版かVercel版か

部屋のサーバーは、Cloudflare版かVercel版のどちらか1つを置きます。
プロトコルとログインは同じで、Axeから見て同じように動きます。

|                | Cloudflare版                                  | Vercel版                                                                    |
| -------------- | --------------------------------------------- | --------------------------------------------------------------------------- |
| 動かす場所     | Cloudflare Workers（Durable Objects、R2）     | Vercel Functions（東京のリージョン）、Redis、Vercel Blob                    |
| 要るアカウント | Cloudflare（R2の申し込みに支払い方法が要る）  | Vercel（Redisは、VercelのMarketplaceから無料のものを作れる）                |
| WebSocket      | つなぎっぱなし                                | 数分ごとに部屋のサーバーが閉じ、Axeが静かにつなぎ直す（VercelのWebSocketはベータ） |
| 費用の見込み   | 無料のプランで、1日に5〜7卓ほど               | 卓の時間と人数に応じて、Functionの時間とRedisとBlobの使用量が増える         |
| 向いている人   | 部屋のサーバーを長く安定して置きたい人        | すでにVercelを使っていて、トークン発行と1つのデプロイで済ませたい人         |

迷ったら、**Cloudflare版**が向きます。
料金の目安は[料金と上限](/operate/costs)にあります。

## 組み合わせの例

| やりたいこと                           | 置くもの                                     |
| -------------------------------------- | -------------------------------------------- |
| まず動かしてみたい                     | Vercel版（トークン発行）                     |
| 借りているレンタルサーバーで済ませたい | PHP版                                        |
| SkyWayを使わずに遊びたい               | Cloudflare版                                 |
| SkyWay版とサーバー版を1か所で置きたい  | Vercel版（トークン発行と部屋のサーバーの両方） |
| 身内用と公開用を分けたい               | それぞれを2つずつ置く                        |

どのサーバーも、名前を変えれば同じアカウントにいくつでも置けます。
Cloudflare版は、Workerの名前を変えてデプロイすれば、R2のバケット、部屋、レート制限がWorkerごとに分かれます。
