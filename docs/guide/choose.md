# どれを使うか

このページでは、いまのSkyWay版の配信で、どのサーバーを使うかを選ぶ目安を説明します。
トークン発行サーバーは、PHP版かVercel版のどちらか1つを選びます。
アセットサーバー（Cloudflare版）は、必要なら足します。

サーバー版（開発中）では、Cloudflare版だけで遊べるようになり、トークン発行サーバーは要らなくなります。
詳しくは[今後の計画](/guide/roadmap)を見てください。

## トークン発行サーバー：PHP版かVercel版か

どちらもAxeから見て同じように動きます。
違うのは、どこで動かすかと、手間のかかりかたです。

|                    | PHP版                                           | Vercel版                                      |
| ------------------ | ----------------------------------------------- | --------------------------------------------- |
| 動かす場所         | レンタルサーバー（Apache＋PHP 8.3 / 8.4 / 8.5） | Vercel Functions（東京リージョン）            |
| 費用               | 契約中のサーバーがあれば追加はなし              | Vercelの無料プラン（Hobby）で足りることが多い |
| 設置のしかた       | zipを展開してFTPで置き、`.env`を書く            | Deployボタンを押して環境変数を入れる          |
| サーバーの管理     | レンタルサーバーの管理画面で行う                | 要らない                                      |
| トークンの有効期間 | 24時間（固定）                                  | 既定24時間。60秒〜7日の間で変えられる         |
| 向いている人       | すでにレンタルサーバーを借りている人            | サーバーを持っていない人、手早く済ませたい人  |

迷ったら、**Vercel版**がいちばん手軽です。
すでにPHPの動くレンタルサーバーを借りているなら、契約を増やさずに済む**PHP版**が向きます。

::: tip 本家のバックエンドも使えます
本家ユドナリウムの[udonarium-backend](https://github.com/TK11235/udonarium-backend)も、Axeが呼び出すAPI（`GET /v1/status`と`POST /v1/skyway2023/token`）に対応しているので、そのまま使えます。
:::

## アセットサーバー：Cloudflare版を足すかどうか

アセットサーバーは**なくても遊べます**。
次のような卓では、足すと効果があります。

- 参加者が多い（5人以上など）
- 画像や音声が多い部屋を使う
- 回線の細い参加者がいる

アセットサーバーがないと、画像は持っている人から1人ずつP2Pで受け取ります。
アセットサーバーがあると、全員がCloudflareの近くのデータセンターから受け取れるので、早く行き渡ります。

一方で、次のことは知っておいてください。

- CloudflareのアカウントでR2を使い始める申し込みが要ります（アカウントに一度だけ。無料枠があります）。バケットはデプロイのときに自動で作られます。
- 置いた画像と音声は、名前（中身のSHA-256）を知っていれば誰でも読めます。名前は中身から計算されるので推測はできませんが、メンバー以外から完全に隠したい素材には向きません。
- アップロードを受けるのは、許可したOriginのページからだけです。ただしOriginはブラウザ以外からなら偽れるので、これは乱用を抑える制限です。ログインした人だけが置けるようにするのは、サーバー版の部屋ができてからです。

詳しくは[安全のしくみ](/cloudflare/security)を見てください。

## 組み合わせの例

| やりたいこと                           | 組み合わせ                            |
| -------------------------------------- | ------------------------------------- |
| まず動かしてみたい                     | Vercel版だけ                          |
| 借りているレンタルサーバーで済ませたい | PHP版だけ                             |
| 大人数の卓を快適にしたい               | Vercel版（またはPHP版）＋Cloudflare版 |
| 身内用と公開用を分けたい               | それぞれの組み合わせを2組用意する     |

Cloudflare版は、同じCloudflareアカウントに何台でも置けます。
身内用と公開用を分けるときも、Workerの名前を変えてデプロイすれば、R2のバケットとレート制限はWorkerごとに分かれます。
