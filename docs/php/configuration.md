# PHP版の設定項目

PHP版は、`.env`というテキストファイルから設定を読みます。
このページでは、書ける項目と、ファイルの探しかたを説明します。

## 項目

| 名前                          | 必須 | 既定値 | 内容                                                                  |
| ----------------------------- | :--: | ------ | --------------------------------------------------------------------- |
| `SKYWAY_APP_ID`               |  ✅  | —      | SkyWayのアプリケーションID                                            |
| `SKYWAY_SECRET`               |  ✅  | —      | SkyWayのシークレットキー。トークンの署名に使う                        |
| `ACCESS_CONTROL_ALLOW_ORIGIN` |      | 空     | トークンの発行を受けるOrigin。カンマ区切りで複数書ける                |
| `SKYWAY_UDONARIUM_LOBBY_SIZE` |      | `3`    | ロビーの数（1以上の整数）。[トークン発行のしくみ](/token/#ロビーの数) |

### `ACCESS_CONTROL_ALLOW_ORIGIN`

Axeを配信しているページのOriginを書きます。

```dotenv
# 1つだけ
ACCESS_CONTROL_ALLOW_ORIGIN="https://axe.example.com"

# 複数
ACCESS_CONTROL_ALLOW_ORIGIN="https://axe.example.com,https://www.axe.example.com"
```

- Originは、スキーム（`https://`）・ホスト名・ポートがすべて一致したときだけ通します。
- 末尾に`/`を付けないでください。PHP版は、ここに書いた文字列をそのままブラウザに返すので、`/`が付いているとブラウザが「Originが違う」と判断して通信を止めます。
- 空のままだと、どのOriginからのトークン発行も断ります。
- `*`と書くと、すべてのOriginを許可します。試すときだけにしてください。ほかのサイトに置かれたAxeからも、あなたのSkyWayアプリが使えてしまいます。

### `SKYWAY_UDONARIUM_LOBBY_SIZE`

ロビー（部屋の一覧を見るためのチャンネル）の数です。
Axeは1番のロビーから順に見て、300人に満たないところに入ります。
同時にロビーにいる人が数百人を超えるときに増やします。
同じSkyWayアプリを使うほかのトークン発行サーバーとは、同じ値にそろえてください。

## 値の書きかた

`.env`は、`名前=値`を1行に1つ書きます。

```dotenv
# 「#」で始まる行はコメント
SKYWAY_APP_ID="..."
```

- 値は`"`（ダブルクォート）で囲むことをすすめます。
- 囲まない値に`;`が入っていると、`;`から後ろが切り捨てられます。囲んでおけば、`;`も`#`もそのまま読みます。

## `.env`の探しかた

PHP版は、次の順に`.env`を探し、最初に見つかったものを読みます。

1. 環境変数`ENV_PATH`に書かれた場所（`.htaccess`の`SetEnv ENV_PATH /path/to/.env`などで設定する）
2. `index.php`と同じフォルダの`.env`
3. `index.php`の1つ上のフォルダの`.env`

どこにも無いときや、必須の値が欠けているときは、すべてのリクエストに`500`を返します。

3番目は、`index.php`をドキュメントルートの直下に置いたときのためのものです。
サブディレクトリやサブドメインに置いたときは、`index.php`の1つ上のフォルダは公開フォルダの中なので、そこに`.env`を置かないでください（→ [もっと安全にしたいとき](/php/setup#もっと安全にしたいとき)）。
原因はPHPのエラーログに出ます。

## `.htaccess`が断るもの

付属の`.htaccess`は、次のものへのWebからのアクセスを断ります。
設定を書き換えるときは、これらが見えるようにならないよう気をつけてください。

- 名前が`.`で始まるファイルとフォルダ（`.env`、`.git`など）。ただし`.well-known/`は通す（SSL証明書の発行で使うため）
- `composer.json`、`phpunit.xml`、`Dockerfile`など開発用のファイル
- `vendor/`、`tests/`、`bin/`、`docs/`などのフォルダ
