# PHP版

SkyWay版の配信で使う認証トークンを発行する、PHPで書いたサーバーです。
レンタルサーバー（Apache＋PHP）の公開フォルダに置き、`.env`を書くだけで動きます。
データベースもコマンド操作も要りません。

::: info 部屋のサーバー（サーバー版）はありません
レンタルサーバーのPHPは、WebSocketをつなぎっぱなしにできないので、PHP版はSkyWayのトークン発行だけを受け持ちます。
サーバー版で配信するときは、[Cloudflare版](/cloudflare/)か[Vercel版](/vercel/#部屋のサーバー)を使ってください。
:::

## できること

- SkyWayの認証トークンを発行する（`POST /v1/skyway2023/token`）
- 動いているかを返す（`GET /v1/status`）
- 許可したOriginのページからのリクエストだけを受ける（CORS）
- `.env`やソースコードなど、見られては困るファイルへのアクセスを`.htaccess`で断る
- サブディレクトリ（例：`https://example.com/backend/`）に置いても動く

APIの詳しい形は[APIリファレンス](/token/api)にあります。

## 必要なもの

| もの           | 条件                                                         |
| -------------- | ------------------------------------------------------------ |
| PHP            | 8.3、8.4、8.5のいずれか                                      |
| Webサーバー    | Apache。`mod_rewrite`が使え、`.htaccess`での設定を許している |
| HTTPS          | Axeを`https://`で配信するなら、こちらも`https://`で公開する  |
| SkyWayのアプリ | アプリケーションIDとシークレットキー                         |

多くのレンタルサーバー（さくらのレンタルサーバ、ロリポップ、エックスサーバーなど）は、この条件を満たしています。
PHPの版は、サーバーの管理画面で選べることが多いです。

::: warning PHP 8.2以前では動きません
PHP 8.3で入った書き方を使っているので、8.2以前ではエラーになります。
管理画面でPHPの版を8.3以上に切り替えてから設置してください。
:::

## 配布物の中身

[リリース](https://github.com/Xelltis/udonarium_axe_backend/releases/latest)のzip（`udonarium-axe-backend-<版>.zip`）には、次のものが入っています。
展開した中身が、そのまま公開フォルダの中身になります。

| ファイル                                   | 役割                                                      |
| ------------------------------------------ | --------------------------------------------------------- |
| `index.php`                                | すべてのリクエストの入口                                  |
| `.htaccess`                                | URLの振り分けと、見られては困るファイルへのアクセスの遮断 |
| `.env.example`                             | 設定ファイルのひな形。コピーして`.env`を作る              |
| `src/`                                     | 本体のプログラム                                          |
| `docs/`                                    | 説明書（Webからは見えないようにしてある）                 |
| `README.md`・`LICENSE`・`CHANGELOG.md`など | 説明と、ライセンスと、変更の記録                          |
