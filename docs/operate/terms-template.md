# 利用規約のひな形

部屋のサーバー（Cloudflare版かVercel版）を公開して運営する人が、利用規約を書くときの下書きです。
〔　〕の中を運営に合わせて書き換え、運営に合わない項目を直してから載せてください。
部屋が消えるときや、申し立てを受けたときの手順は[運営の方針](/operate/policies)と同じです。

::: warning 法律の助言ではありません
このひな形は、部屋のサーバーのしくみをもとに書いたものです。
公開する前に、ご自身で、必要なら専門家に確かめてください。
:::

## 本文

この規約は、〔運営者の名前〕（以下「運営者」）が運営する〔サービスの名前〕（Udonarium Axeと、その部屋のサーバー。以下「本サービス」）を使う人に適用されます。
本サービスを使った人は、この規約に同意したものとみなします。

### 1. アカウント

本サービスのログインには、Discordのアカウントを使います。
ログインしないで部屋に入った人は、見学者として扱われます。
アカウントは、Udonarium Axeのロビーの上にあるアカウント欄から、いつでも削除できます。

### 2. 置いてはいけないもの

部屋に次のものを置いたり、チャットに書いたりしてはいけません。

- 他人の著作権、肖像権、プライバシーなどの権利を侵すもの
- 法令や公序良俗に反するもの
- 〔運営に合わせて足すもの〕

### 3. 削除

権利者から申し立てを受けたときや、前条に当たると運営者が判断したときは、予告なく、部屋に置かれた画像や音声を削除し、同じものを置けなくすることがあります。
申し立ては、〔申し立ての窓口（メールアドレスやフォーム）〕で受け付けます。

### 4. 部屋が残る期間

部屋は、最後の1人が抜けてから〔24〕時間たつと、卓の状態、画像、音声とともに消えます。
運営者はバックアップを取りません。
残したい卓は、Udonarium Axeの保存で、各自の手元に保存してください。続きに使うのは、GMの保存です（GM以外の人の保存には、その人に見えていなかった物が欠けた形で入ります）。

### 5. 本サービスの停止と変更

運営の都合で、予告なく本サービスを止めたり、内容を変えたりすることがあります。

### 6. 責任

本サービスは、そのままの状態で提供します。
消えたデータや、本サービスを使ったことで生じた損害について、運営者は、運営者に故意または重大な過失があるときを除き、責任を負いません。

### 7. この規約の変更

この規約を変えるときは、本サービスのページでお知らせします。
お知らせのあとに本サービスを使った人は、変えたあとの規約に同意したものとみなします。

### 8. 準拠法と管轄

この規約は〔日本法〕にしたがって解釈します。
本サービスについて争いが起きたときは、〔裁判所の名前〕を第一審の専属的合意管轄裁判所とします。
