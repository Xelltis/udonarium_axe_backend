# プライバシーポリシーのひな形

部屋のサーバー（Cloudflare版かVercel版）を公開して運営する人が、プライバシーポリシーを書くときの下書きです。
〔　〕の中を運営に合わせて書き換え、運営に合わない項目を直してから載せてください。
預かるものと消えるときは[運営の方針](/operate/policies)の表と同じです。
部屋のサーバーの設定（`ROOM_RETENTION_HOURS`など）を変えたときは、それに合わせて直します。
〔Cloudflare版のとき〕〔Vercel版のとき〕と書いたところは、使っている方だけを残します。

::: warning 法律の助言ではありません
このひな形は、部屋のサーバーのしくみをもとに書いたものです。
公開する前に、ご自身で、必要なら専門家に確かめてください。
:::

## 本文

〔運営者の名前〕（以下「運営者」）は、〔サービスの名前〕（Udonarium Axeと、その部屋のサーバー。以下「本サービス」）で預かる情報を、次のとおり扱います。

### 1. 預かる情報

本サービスは、次の情報を預かります。

- Discordでログインしたとき：DiscordのユーザーID、表示名、アバターのURLと、本サービスが割り当てるユーザーID
- ログインを続けるための情報：リフレッシュトークンのハッシュ（トークンそのものは預かりません）
- 部屋の情報：部屋の名前、表示用のID、パスワードのハッシュ、人数、部屋のGMのユーザーID、参加した人のユーザーIDごとの役割、部屋を作った人のDiscordのユーザーIDと送信元のIPアドレス
- 部屋に入っている人の情報：送信元のIPアドレスとDiscordのユーザーID（部屋を抜けるまで）
- 卓の状態：コマ、カード、チャットの発言など、部屋で作られたもの
- 部屋に置かれた画像と音声、置いたときのファイル名
- 部屋の記録：部屋の鍵と、部屋で起きたこと（入った、出た、断った、削除した、ダイスを振ったなど）、そのときの役割や断った理由（だれのことかは含みません）
- アクセスの記録：本サービスへのリクエストの記録（送信元のIPアドレスを含みます）
- 不正な使い方を防ぐための記録：ログイン、部屋の作成、画像と音声の保存、短いあいだのリクエストが多すぎたときなどの時刻と、送信元のIPアドレス、DiscordのユーザーIDと表示名
- 利用を止めた記録：運営者が利用を止めたIPアドレスの範囲かDiscordのユーザーIDと、その理由

次の情報は求めず、預かりません。

- Discordのメールアドレスと、参加しているDiscordのサーバー
- Discordのアクセストークン（ログインのときに、その人の情報を1度読むのに使うだけです）

部屋のサーバーはcookieを使いません。ログインのトークンは、利用する人のブラウザに置かれます。

### 2. 使う目的

預かった情報は、次のことに使います。

- ログインして部屋に入り、部屋ごとの役割を守る
- 卓の状態を残し、部屋の参加者に配る
- 部屋に置かれた画像と音声を、その部屋の参加者に配る
- 不正な使い方を防ぎ、障害を調べる
- 不正な使い方をする送信元やアカウントの利用を止める

送信元のIPアドレスは、短いあいだに来たリクエストの数を数えるのにも使います。数えたものは置いておきません。

運営者が、部屋に置かれた画像と音声の中身を見るのは、権利侵害の申し立てや不正な使い方に応えるときだけです。
見たときは、そのことを記録に残します。

### 3. 預ける先

〔Cloudflare版のとき〕本サービスは、Cloudflare, Inc.のサービス（Workers、Durable Objects、R2、Workers Analytics Engine）の上で動いています。
預かった情報は、Cloudflareのデータセンターに置かれます。

〔Vercel版のとき〕本サービスは、Vercel Inc.のサービス（Vercel Functions、Vercel Blob）と、〔Redisの提供元（例：Upstash, Inc.）〕のサービスの上で動いています。
預かった情報は、それぞれのデータセンターに置かれます。
ログインには、Discord Inc.のサービスを使います。

Udonarium Axeの画面は、ほかに次の4つで外のサービスにつながります。そのとき、利用する人のブラウザがそれぞれのサービスに直接つながり、情報はそのサービスの定めにしたがって扱われます。

- 部屋に置かれたYouTubeの動画を、YouTubeの埋め込みで再生する（YouTubeはcookieを使うことがあります）
- ログインした人のアバターを、部屋の参加者それぞれのブラウザがDiscordの配信元から読み込む
- 参加者がURLで足した画像を、部屋の参加者それぞれのブラウザがその画像の置き場から読み込む
- キャラクターシートを取り込むとき、取り込む人のブラウザがキャラクターシートの保管サイトにつながる

### 4. 消えるとき

| 情報                                       | 消えるとき                                                                                                |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| アカウント                                 | 本人がアカウントを削除したとき                                                                            |
| リフレッシュトークン                       | 30日で使えなくなります。ログアウトしたときと、アカウントを削除したときにも消えます                        |
| 部屋の情報、卓の状態、画像と音声           | 最後の1人が部屋を抜けてから〔24〕時間たったとき。部屋のGMか運営者が部屋を削除したときは、その場で消えます |
| 画像と音声の写し（〔Cloudflare版のとき〕） | Cloudflareのデータセンターのキャッシュに最長7日残ります。部屋を削除したあとに読めるのは最長15分です       |
| 部屋の記録、アクセスの記録                 | 〔Cloudflare／Vercel〕が定める期間                                                                        |
| 不正な使い方を防ぐための記録               | 7日たったとき。2000件を超えたときは、古いものから（運営者の操作の記録は90日）                             |
| 利用を止めた記録                           | 運営者が止めるのをやめたとき。決めた期間が過ぎたとき                                                      |

アカウントは、使われなくなっても自動では消えません。

### 5. アカウントの削除

Udonarium Axeのロビーの上にあるアカウント欄の「アカウントを削除」で、いつでも削除できます。
アカウントの情報とすべてのトークンが消えます。
入ったことのある部屋には、そのユーザーIDと、部屋で書いたチャットの発言などが、部屋が消えるまで残ります。

### 6. 第三者への提供

法令にもとづく場合を除き、預かった情報を第三者に提供しません。

### 7. このポリシーの変更

このポリシーを変えるときは、本サービスのページでお知らせします。

### 8. 問い合わせ

このポリシーと、預かった情報についての問い合わせは、〔問い合わせ先（メールアドレスやフォーム）〕で受け付けます。
