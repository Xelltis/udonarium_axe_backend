# v1.6.1

2026-11-12リリース

依存パッケージを更新した版です。置く人から見た変更はありません。
新しい設定項目もありません。

## 依存パッケージの更新

- Cloudflare版：`hono` 4.13.17 → 4.13.18、開発用の`wrangler` 4.158.0 → 4.160.1、`@cloudflare/vitest-plugin` 1.6.0 → 1.8.0、`@cloudflare/workers-types` 5.20261107.1 → 5.20261110.1、`typescript-eslint` 8.72.1 → 8.72.2、`prettier` 3.9.10 → 3.10.0
- Vercel版：`hono` 4.13.17 → 4.13.18、`@hono/node-server` 2.1.6 → 2.1.7、`@vercel/blob` 2.8.2 → 2.9.0、`@vercel/functions` 3.11.0 → 3.11.1、`ws` 8.22.1 → 8.22.2、`undici` 7.30.1 → 7.30.2、開発用の`vercel` 65.12.1 → 65.14.0、`typescript-eslint` 8.72.1 → 8.72.2、`prettier` 3.9.10 → 3.10.0
- PHP版：開発用の`friendsofphp/php-cs-fixer` 3.95.29 → 3.95.30、`phpunit/php-code-coverage` 14.5.1 → 14.5.2、`sebastian/version` 7.0.1 → 7.1.0

`hono` 4.13.18と`@hono/node-server` 2.1.7には、セキュリティの直しが入っています。
直された機能（リクエストの本文の検査、静的なファイルの配信など）は、部屋のサーバーでは使っていません。
Vercel版のトークン発行は本文の検査を使いますが、検査を通った値だけを読むので、直された問題は当たりません。

`undici` 7.30.2にも、セキュリティの直しが入っています。
Vercel版の部屋のサーバーは、Vercel Blobとのやりとりに`undici`を使います。
直ったのはリダイレクトをたどるときとキャッシュを使うときの問題で、部屋のサーバーの使いかたには当たりません。
Cloudflare版の開発用の道具が使う`undici`も、同じ版にそろえました。こちらは、デプロイした部屋のサーバーには入っていません。

手で置くときに使うCLIも上がります。`npx wrangler`で動くのはwrangler 4.160.1に、`npx vercel`で動くのはVercel CLI 65.14.0になります。
このサイトの手順で使うオプションは変わっていません。

## Node.jsのセキュリティリリース

2026年11月11日に、Node.jsのセキュリティリリース（24系はv24.22.3）が出ました。
直ったのは、HTTP/2、TLSのサーバー、zlib、Permission Modelなどの問題です。

Cloudflare版の部屋のサーバーはWorkersで動き、Node.jsは使いません。

Vercel版の部屋のサーバーはNode.jsで動きますが、番号の付いた問題（CVE）は、どれも部屋のサーバーが使っていない機能のものです。
HTTPSはVercelが手前で受けるので、部屋のサーバーはTLSのサーバーを立てません。
Node.jsのマイナー版とパッチ版は、セキュリティの直しなどのときにVercelが自動で更新します。
この版にしてデプロイし直すと、そのときの24系の最新で動きます。

## この版にするとき

- **部屋のサーバー（Cloudflare版・Vercel版）**：用意するものも、設定の変更もありません。
- **Axe**：そのまま使えます。やりとりの版（`PROTOCOL_VERSION`）は6のままです。
- **SkyWay版のトークン発行とPHP版**：v1.6.0と同じです。置いている人がすることはありません。
