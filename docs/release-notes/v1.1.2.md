# v1.1.2

2026-10-18リリース

Discordのログインが部屋のサーバーで失敗したときに、その理由をログに残すようにしました。
置く人に向けたリリースノートも、このサイトに載せました。

## ログインが失敗したときのログ

Axeに「Discordとのやりとりに失敗しました」と出たとき（`login_error=provider-failed`）、部屋のサーバーのログに理由が出ます。
これまでは何も残らなかったので、Client Secretが違うのか、同じコードを2回使ったのかを見分けられませんでした。

ログには、失敗したところ（トークンの引き換えか、本人の情報を読むところ）と、Discordの答えが、次のように出ます。
Discordの答えには理由だけが入り、ログインのコードやトークンは入りません。

```text
Discord turned the login down at the token request: 401 {"error": "invalid_client"}
```

ログの見るところと、理由ごとの直しかたは、[ログインできない](/server/troubleshooting#ログインできない)にあります。
