# v1.0.0

2026-04-19リリース

PHP版の`src/`の中を、役目ごとのフォルダに分け直しました。
`.htaccess`で、見せてはいけないフォルダをWebから読めないようにしました。

## src/の分け直し

`src/`の中のファイルを、設定、リクエストの扱い、トークンの発行などの役目ごとのフォルダに分けました。

## Webから読めないもの

`.htaccess`で、置いてあっても見せてはいけないフォルダ（`vendor/`・`tests/`・`bin/`・`docs/`・`node_modules/`など）を、Webから読めないようにしました。

## この版にするとき

`src/`を丸ごと置き換えてください。
ファイルの場所が変わったので、一部だけを置き換えると動きません。
`.env`はそのまま使えます。
