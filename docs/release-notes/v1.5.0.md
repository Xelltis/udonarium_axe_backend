# v1.5.0

2026-11-01リリース

Axe v1.75.0で入ったシーンとシナリオテキストを、部屋のサーバーでGMのものとして扱うようになりました。
シナリオテキストはGMにしか届けず、シーンとシナリオテキストを作る・書き換える・消すのもGMにしか許しません。
新しい設定項目はありません。やりとりの版（`PROTOCOL_VERSION`）は4のままです（→ [この版にするとき](#この版にするとき)）。

## シナリオテキストをGMにだけ届ける

シナリオテキストは、GMがセッションの前に書いておき、あとでチャットへ送る文です。
送る前の描写や真相が書かれているので、部屋のサーバーはシナリオテキストをGMにしか届けません。PLや見学のブラウザには、データも届きません。

シーンは、これまでどおり全員に届きます。盤面のスイッチは押した人の画面でシーンを反映するので、PLの手元にもシーンが要るためです（→ [わざと隠さないもの](/server/#わざと隠さないもの)）。

## シーンとシナリオテキストを書き換えられるのはGMだけ

GMでない人が、シーンやシナリオテキストを作る・書き換える・消すと、部屋のサーバーは断ります。
PLがシーンを書き換えたときは、部屋のサーバーが持っているシーンを、その人に送り返します。
シーンは全員に届くので、改造したAxeでも、PLがGMのシーンを書き換えることはできません。

## この版にするとき

- **部屋のサーバー（Cloudflare版・Vercel版）**：用意するものも、設定の変更もありません。
- **Axe**：やりとりの版は変わらないので、v1.73.0以降のAxeとそのまま使えます。シーンとシナリオテキストを作るのは、v1.75.0以降のAxeです。
- **SkyWay版のトークン発行とPHP版**：変更はありません。
