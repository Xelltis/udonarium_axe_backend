# v1.0.2

2026-08-11リリース

PHP版で、リポジトリの`stubs/`をWebから読めないようにしました。

## Webから読めないもの

リポジトリを丸ごとドキュメントルートにして動かしたとき、`stubs/`の中のファイルがWebから読めました。
`.htaccess`で、`vendor/`や`tests/`と同じく読めないようにしました。

配布用のzipには`stubs/`が入っていないので、zipから置いた人には関係しません。

## この版にするとき

リポジトリを丸ごと置いている人（`git pull`で更新している人など）は、この版にしてください。
zipから置いている人は、`.htaccess`を置き換えるだけで構いません。
