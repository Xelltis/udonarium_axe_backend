# v1.4.1

2026-11-01リリース

依存パッケージを更新した版です。置く人から見た変更はありません。
新しい設定項目もありません。

## 依存パッケージの更新

Dependabotの11件を取り込みました。

- Cloudflare版：`hono` 4.13.13 → 4.13.14、開発用の`wrangler` 4.153.0 → 4.154.0、`@cloudflare/vitest-plugin` 1.4.8 → 1.4.9、`@cloudflare/workers-types` 5.20261024.1 → 5.20261028.1、`typescript-eslint` 8.72.0 → 8.72.1
- Vercel版：`hono` 4.13.13 → 4.13.14、`@vercel/functions` 3.10.3 → 3.10.4、開発用の`vercel` 65.2.0 → 65.5.0、`tsx` 4.23.12 → 4.23.15、`typescript-eslint` 8.72.0 → 8.72.1
- PHP版：開発用の`phpunit/phpunit` 13.4.3 → 13.4.5、`phpstan/phpstan` 2.3.1 → 2.3.3
- このサイト：`vitepress` 2.0.0-alpha.20 → 2.0.0-alpha.21

`hono`と`@vercel/functions`は、デプロイした部屋のサーバーの中で動きます。
どちらの直しも、部屋のサーバーが使っているところには当たらないので、動きは変わりません。

手で置くときに使うCLIも上がります。`npx wrangler`で動くのはwrangler 4.154.0に、`npx vercel`で動くのはVercel CLI 65.5.0になります。
Vercel CLIは65.4.0でいくつかのオプションの名前を変えましたが、このサイトの手順で使うオプションは変わっていません。

## この版にするとき

- **部屋のサーバー（Cloudflare版・Vercel版）**：用意するものも、設定の変更もありません。
- **Axe**：そのまま使えます。やりとりの版（`PROTOCOL_VERSION`）は4のままです。
- **SkyWay版のトークン発行とPHP版**：v1.4.0と同じです。置いている人がすることはありません。
