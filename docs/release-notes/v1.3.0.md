# v1.3.0

2026-10-24リリース

部屋のPLが、自分で足した画像と音声を、部屋から消せるようになりました。
Axeで画像のタグを自分専用にしたときの記録も、鍵をかけた人とGMだけが変えられるようにしました。
どちらも、Axe v1.70.0の新しい機能に合わせたものです。
新しい設定項目はありません。

## PLが自分で足した画像と音声を消す

v1.2.0では、部屋の画像と音声を消せるのは、いまGMとして部屋にいる人だけでした。
この版からは、いまPLとして部屋にいて、その画像か音声を足した人も消せます（→ [`DELETE /v1/rooms/:roomKey/assets/:sha256`](/reference/server-api#delete-v1-rooms-roomkey-assets-sha256)）。
GMは今までどおり、どの画像と音声も消せます。

足した人は、Axeが部屋に書く記録（`asset-owner`）で見分けます。
PLが書けるのは、自分を足した人とする記録だけです。ほかの人の記録は書き換えられないので、先に足した人が、足した人として残ります。
消したことの記録（`asset-removal`）も、PLは自分が足した画像と音声についてだけ書けます。消したものを戻せるのは、今までどおりGMだけです。
記録の無い画像と音声（v1.70.0より前のAxeで足したもの）は、GMだけが消せます。

## 自分専用のタグ

Axe v1.70.0では、画像のタグに鍵をかけると、そのタグの画像が、鍵をかけた人とGMの画面にだけ出ます。
部屋のサーバーは、その鍵の記録（`image-tag-lock`）を、鍵をかけた人とGMだけが変えられるようにします。
画像そのものは、今までどおり部屋にいる全員に配ります。隠すのはAxeの画面です。

記録の決まりは、開発者向けの[部屋のプロトコル](https://github.com/Xelltis/udonarium_axe_backend/blob/main/development/protocol.md)にあります。

## この版にするとき

- **部屋のサーバー（Cloudflare版・Vercel版）**：用意するものはありません。設定もそのままで動きます。
- **Axe**：そのまま使えます。PLが自分の画像と音声を消すこと、タグを自分専用にすることは、v1.70.0以降のAxeだけができます。
- **SkyWay版のトークン発行とPHP版**：v1.2.0と同じです。置いている人がすることはありません。

v1.2.0以前の部屋のサーバーでは、v1.70.0のAxeのPLが画像と音声を消そうとしても、取り消されます。
