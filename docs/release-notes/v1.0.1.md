# v1.0.1

2026-08-06リリース

PHP版で、2つの弱いところを直しました。
SkyWay版のトークン発行を置いている人は、この版にしてください。

## 頼まれた範囲を超えるトークン

トークンを頼むときの`channelName`と`peerId`は、これまで型と長さしか確かめていませんでした。
SkyWayは、名前の中の`*`を「どんな文字列にも当てはまる」と、`\`をその打ち消しと読みます。
そのため、`channelName`に`*`を渡すだけで、アプリの中のすべての部屋を読み書きできるトークンが出せていました。
ロビーの名前（`udonarium-lobby-`で始まるもの）を渡すと、ロビーで書けないようにしている権限が付いたトークンも出せました。

次の値は、`400`で断るようにしました（→ [トークン発行のAPI](/reference/token-api)）。

- 空の`channelName`と`peerId`
- `*`か`\`を含む`channelName`と`peerId`
- `udonarium-lobby-`で始まる`channelName`

## Webから読めないもの

`.git`のような、`.`で始まるフォルダの中のファイルが、Webから読めました。
`git pull`で置いている環境では、ソースコードとコミットの履歴がすべて見えていました。
`.htaccess`で、`.`で始まるフォルダを`403`で断るようにしました。
証明書の確かめに使う`.well-known/`だけは、これまでどおり読めます。

## この版にするとき

zipの中身を置き換えます。
`.htaccess`も新しいものにしてください。
