# v1.3.1

2026-10-27リリース

Cloudflare版の部屋のサーバーが、SQLiteに書く行と読む行を大きく減らしました。
無料のプランで遊べる卓が、1日に2卓ほどから25卓ほどに増えます。
入室と、しばらく静かだった部屋での最初の操作も速くなりました。
新しい設定項目はありません。

## 無料のプランで遊べる卓

2026年10月26日に本番の卓を測ったところ、Cloudflare版で最初に尽きるのは、Durable ObjectsのSQLiteに書く行（無料のプランで1日10万行）でした。
v1.3.0までは、部屋のオブジェクトを1つずつ1行に置いていたので、部屋のデータを読み込むだけで約3万行を書いていました。
この版からは、オブジェクトを約8KiBずつ1行にまとめて置きます。

| 4時間の卓                   | v1.3.0    | v1.3.1    |
| --------------------------- | --------- | --------- |
| SQLiteに書く行              | 約4万行   | 約4,000行 |
| SQLiteから読む行            | 約126万行 | 約3.2万行 |
| 無料のプランで1日に遊べる卓 | 2卓ほど   | 25卓ほど  |

次に当たる上限は、Durable Objectsのリクエスト（1日に30卓ほど）です。
有料のプランの月額の見込みも下がりました（→ [費用と上限](/operate/costs)）。

ログインした人のいる部屋では、見回りのアラームが15分ごとに起きていました。トークンを更新しても、見回りの時刻が古い期限のまま残っていたためです。この版から、見回りは1時間に1回ほどになります。

## 速くなったところ

約1.4万オブジェクトの部屋を手元で再現して測ると、次のように変わりました。

| 待つもの                                                       | v1.3.0  | v1.3.1  |
| -------------------------------------------------------------- | ------- | ------- |
| 入ってきた人が、部屋の全部を受け取るまで                       | 約2.2秒 | 約0.4秒 |
| しばらく静かだった部屋で、最初の操作がほかの人に届くまで       | 約47ms  | 約24ms  |
| 部屋のデータを読み込んだ直後の操作が届くまで（遅いほうから1%） | 約140ms | 約8ms   |

ふだんの操作がほかの人に届くまでの時間（約2ms）と、ダイスの結果が届くまでの時間は変わりません。

## この版にするとき

- **Cloudflare版**：用意するものも、設定の変更もありません。デプロイしたあとに作った部屋から、新しい置きかたになります。
  - この版より前に作った部屋は、消えるまで前の置きかたのままです。部屋は、最後の人が抜けてから保持期間（既定24時間）がたつと消えます。
  - **この版で作った部屋は、v1.3.0以前に戻すと開けません。** 戻すと、そのあいだに作った部屋は使えなくなります。
- **Vercel版**：置く人から見た変更はありません。
- **Axe**：そのまま使えます。
- **SkyWay版のトークン発行とPHP版**：v1.3.0と同じです。置いている人がすることはありません。
