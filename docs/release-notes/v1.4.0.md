# v1.4.0

2026-10-28リリース

ログインして入った人が、自分で見学に切り替え、元の役割に戻れるようになりました。
Axe v1.73.0の新しい機能に合わせたものです。
新しい設定項目はありません。
やりとりの版が上がったので、部屋のサーバーとAxeは一緒に更新してください（→ [この版にするとき](#この版にするとき)）。

## 見学への切り替え

v1.3.1までは、役割を変えられるのはGMだけで、ログインしてPLやGMとして入った人は、自分で見学になれませんでした。
この版からは、ログインした人が自分の役割を見学に変え、見学から元の役割に戻れます（→ [見学に切り替える](https://github.com/Xelltis/udonarium_axe_backend/blob/main/development/room-server.md#見学に切り替える)）。

- 部屋のサーバーが覚えている役割は変わりません。GMが見学に切り替えても、部屋のGMの数はそのままです。戻れば、またGMとして操作できます。
- 見学していることは、部屋のサーバーが覚えます。入り直しても見学のまま席に着き、戻るか、GMがその人の役割を変えるまで続きます。
- 同じ人がほかのタブや端末で入っている席も、一緒に切り替わります。
- 入ったときと役割が変わったときに、ログインした人へ、覚えている役割（`keptRole`）を知らせます。この欄を足したので、やりとりの版（`PROTOCOL_VERSION`）を3から4に上げました。

## 依存パッケージの更新

Dependabotの4件を取り込みました。

- PHP版のDockerイメージ：`php` 8.5.11-apache → 8.5.12-apache
- Vercel版：`@vercel/functions` 3.10.2 → 3.10.3、開発用の`vercel` 65.0.0 → 65.2.0
- Cloudflare版：開発用の`@cloudflare/workers-types` 5.20261023.1 → 5.20261024.1

## この版にするとき

- **部屋のサーバー（Cloudflare版・Vercel版）**：用意するものも、設定の変更もありません。
- **Axe**：v1.73.0以降のAxeが要ります。部屋のサーバーと一緒に更新してください。それより前のAxeでは部屋に入れず、ページを読み込み直すよう案内が出ます。反対に、v1.73.0以降のAxeは、v1.3.1以前の部屋のサーバーには入れません。
- **SkyWay版のトークン発行とPHP版**：PHP版のDockerイメージのPHPが8.5.12になります。置いている人がすることはありません。
