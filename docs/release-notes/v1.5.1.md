# v1.5.1

2026-11-07リリース

Vercel版の部屋のサーバーが、つなぎかけの接続を切られると止まっていたのを直した版です。依存パッケージも更新しました。
新しい設定項目はありません。やりとりの版（`PROTOCOL_VERSION`）は4のままです（→ [この版にするとき](#この版にするとき)）。

## Vercel版：つなぎかけの接続を切られても止まらない

部屋に入るとき、Axeは部屋のサーバーとのつなぎかたをWebSocketに切り替えます。
Vercel版は、切り替える前に、AxeのOrigin、部屋の鍵、部屋の人数を確かめます。
これまでは、その確かめているあいだに相手が接続を切ると、部屋のサーバーが止まっていました。
同じインスタンスにつながっていた人は、どの部屋の人も、いったん切れていました。
部屋に入れない人でも、つなぎかけて切るだけで止められました。

いまは、切られた接続だけを閉じ、ほかの接続はそのまま続きます。
Cloudflare版は、この切り替えを自分では受けないので、この問題はありません。

## 依存パッケージの更新

- Cloudflare版：`hono` 4.13.14 → 4.13.17、開発用の`wrangler` 4.155.0 → 4.158.0、`@cloudflare/vitest-plugin` 1.4.10 → 1.6.0、`@cloudflare/workers-types` 5.20261029.1 → 5.20261107.1、`vitest` 5.0.5 → 5.1.0、`eslint` 10.13.0 → 10.14.0
- Vercel版：`hono` 4.13.14 → 4.13.17、`@hono/node-server` 2.1.5 → 2.1.6、`@hono/valibot-validator` 0.6.1 → 0.6.2、`@vercel/functions` 3.10.4 → 3.11.0、`redis` 6.3.0 → 6.3.1、`ws` 8.22.0 → 8.22.1、開発用の`vercel` 65.7.0 → 65.12.1、`vitest` 5.0.5 → 5.1.0、`eslint` 10.13.0 → 10.14.0
- PHP版：開発用の`phpunit/phpunit` 13.4.5 → 13.4.6、`phpstan/phpstan` 2.3.4 → 2.3.5、`friendsofphp/php-cs-fixer` 3.95.27 → 3.95.29

`hono` 4.13.16と`@hono/node-server` 2.1.6には、セキュリティの直しが入っています。
直された機能は、部屋のサーバーではほとんど使っていないので、動きは変わりません。
1つだけ、Vercel版は、パスに`\`をそのまま含むリクエストに400で答えるようになりました。Axeは、そういうリクエストを送りません。

開発用の道具が使う`minimatch`と`glob`に見つかった問題（どちらも重さは中程度）も、直った版にそろえました。
どちらも、デプロイした部屋のサーバーには入っていません。

手で置くときに使うCLIも上がります。`npx wrangler`で動くのはwrangler 4.158.0に、`npx vercel`で動くのはVercel CLI 65.12.1になります。
このサイトの手順で使うオプションは変わっていません。

## この版にするとき

- **Vercel版（トークン発行と部屋のサーバー）**：用意するものも、設定の変更もありません。
- **Cloudflare版**：用意するものも、設定の変更もありません。
- **Axe**：そのまま使えます。やりとりの版（`PROTOCOL_VERSION`）は4のままです。
- **PHP版**：変更はありません。上がったのは開発用の道具だけです。
