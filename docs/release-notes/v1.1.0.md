# v1.1.0

2026-10-18リリース

SkyWayを使わずに遊ぶ「部屋のサーバー」（サーバー版）を、ベータとして加えました。
Cloudflare版とVercel版があり、参加者はDiscordでログインして部屋に入ります。
SkyWay版のトークン発行は、Cloudflareにも置けるようになりました。
置く人向けの文書は、このサイトにまとめました。

## 部屋のサーバー（ベータ）

部屋ごとに置かれたサーバーが卓の状態を持ち、参加者のあいだのやりとりを中継します。
SkyWayもトークン発行サーバーも使いません。
くわしいしくみは[サーバー版のしくみ](/server/)に、置きかたは[Cloudflareに置く](/server/cloudflare)と[Vercelに置く](/server/vercel)にあります。

- **ログインと役割**：部屋を作れるのは、Discordでログインした人だけです。作った人がGMになり、ログインして入った人はPL、ログインしていない人は見学になります。GMは、役割の付いた招待リンクを作れます（→ [役割](/server/#役割)）。
- **サーバーで振るダイス**：チャットのダイスは、サーバーの上のBCDiceで振ります。振った人の手元で、結果を書き換えられません。
- **見せないもの**：裏向きのカードの表や、他人宛ての秘話などは、見てはいけない人に届けません。
- **画像と音声**：部屋ごとに預かり、その部屋の参加者だけに配ります。部屋と一緒に消えます（→ [画像と音声](/server/#画像と音声)）。
- **部屋が消えるとき**：最後の1人が抜けてから、既定で24時間たつと、部屋ごと消えます。Axeを開いたまま3時間操作しなかった人は、部屋から外れます（→ [部屋が消えるとき](/server/#部屋が消えるとき)）。

部屋のサーバーには、v1.68.0以降のAxeが要ります。
それより前のAxeでは入れません。

費用の目安は[費用と上限](/operate/costs)に、預かるものと申し立てへの応えかたは[運営の方針](/operate/policies)にあります。

## SkyWay版のトークン発行をCloudflareに置く

Cloudflare版のWorkerに、SkyWayのアプリの値（`SKYWAY_APP_ID`と`SKYWAY_SECRET`）を入れると、SkyWay版のトークン発行を受け持ちます（→ [Cloudflareに置く（SkyWay版）](/skyway/cloudflare)）。
答えは、PHP版・Vercel版と同じです。
部屋のサーバーと同じWorkerで、両方を受け持つこともできます。

Vercel版のトークン発行も、このリポジトリから置けるようにしました（→ [Vercelに置く（SkyWay版）](/skyway/vercel)）。

## PHP版

プログラムの働きは変わりません。
変えたのは、プログラムの中のコメントだけです。

配布用のzipから、`README.md`と`docs/`（手順と仕様）を外しました。
手順と仕様は、このサイトにあります（→ [レンタルサーバーに置く（PHP版）](/skyway/php)、[トークン発行のAPI](/reference/token-api)）。
zipの直下がそのままドキュメントルートになる並びは、前と同じです。

## この版にするとき

- **PHP版**：zipの中身を置き換えます。`.env`はそのまま使えます。
- **SkyWay版のAxe**：トークン発行の答えは前と同じなので、Axeはそのまま使えます。
- **部屋のサーバー**：新しく置くものです。v1.68.0以降のAxeと一緒に使ってください。
