# v1.4.2

2026-11-01リリース

依存パッケージを更新した版です。置く人から見た変更はありません。
新しい設定項目もありません。

## 依存パッケージの更新

Dependabotの2件を取り込みました。

- Vercel版：`redis` 5.12.1 → 6.3.0、開発用の`@types/node` 24.13.3 → 26.6.6

`redis`は、Vercel版の部屋のサーバーがRedisとやりとりするのに使うパッケージです。
6では、やりとりの形（RESP3）と、コマンドの時間切れ（5秒）が既定になりました。
部屋のサーバーは、5のときと同じ形（RESP2）を指定し、コマンドに時間切れを付けずに使うので、動きはv1.4.1と同じです。

## この版にするとき

- **Vercel版**：用意するものも、設定の変更もありません。
- **Cloudflare版**：v1.4.1と同じです。置いている人がすることはありません。
- **Axe**：そのまま使えます。やりとりの版（`PROTOCOL_VERSION`）は4のままです。
- **SkyWay版のトークン発行とPHP版**：v1.4.1と同じです。置いている人がすることはありません。
