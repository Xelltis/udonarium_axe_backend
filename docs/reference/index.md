# リファレンス

サーバーとAxeのあいだでやりとりするものの形と、サーバーの中の動きをまとめた章です。
サーバーやAxeを直したい人、エラーの理由を詳しく知りたい人に向けています。
置いて遊ぶだけなら、読まなくて構いません。

| ページ                                         | 中身                                                                       |
| ---------------------------------------------- | -------------------------------------------------------------------------- |
| [トークン発行のAPI](/reference/token-api)      | SkyWay版のトークン発行サーバー（PHP版とVercel版）が受けるHTTPのAPI         |
| [部屋のサーバーのAPI](/reference/server-api)   | 部屋のサーバー（Cloudflare版とVercel版）が受けるHTTPのAPIと、エラーのコード |
| [部屋のプロトコル](/reference/protocol)        | 部屋に入ったあとの、WebSocketでのやりとり                                  |
| [部屋のサーバーの中の動き](/reference/room-server) | 卓の同期、卓の状態の置き場所、ログインとトークン、役割と招待               |
| [Axeの中の動き](/reference/client)             | サーバー版で、Axeがログイン、画像と音声、つなぎ直しをどう扱うか            |

部屋のサーバーとAxeが共有する型と例は、`apps/cloudflare/contracts/`にあります。
食い違うときは、そちらが正しいものです。
