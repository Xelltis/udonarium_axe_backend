# API リファレンス

## `GET /`

ウェルカムエンドポイント。

**レスポンス:**

```json
{
    "message": "Ready to serve your realm."
}
```

## `GET /v1/status`

ヘルスチェック用エンドポイント。

**レスポンス:**

```
200 OK
```

## `POST /v1/skyway2023/token`

SkyWay 2023 の JWT トークンを発行します。

**リクエスト:**

```json
{
    "formatVersion": 1,
    "channelName": "room-name",
    "peerId": "peer-id"
}
```

| フィールド      | 型       | 必須 | 説明                                       |
| --------------- | -------- | ---- | ------------------------------------------ |
| `formatVersion` | `int`    | ◯    | フォーマットバージョン（`1`）              |
| `channelName`   | `string` | ◯    | ルームチャンネル名（1〜200 文字）          |
| `peerId`        | `string` | ◯    | ピア ID（1〜200 文字）                     |

**`channelName` / `peerId` の制約:**

SkyWay はスコープ内の `name` で `*` をワイルドカード（0 文字以上の任意文字列にマッチ）として、
`\` をそのエスケープ文字として解釈します。これらをそのまま受け付けると、
発行したトークンの権限が意図したチャンネル・メンバーを越えて拡大するため、次を拒否します。

- 空文字列、または 200 文字を超える値
- `*` または `\` を含む値
- `udonarium-lobby-` で始まる `channelName`（ロビーチャンネルの予約プレフィックス）

いずれも `400 Bad Request` を返します。

**レスポンス:**

```json
{
    "token": "eyJ..."
}
```

## エラーレスポンス

すべてのエラーは JSON 形式で返されます。

```json
{
    "error": "エラーメッセージ"
}
```

| ステータス | 条件                                             |
| ---------- | ------------------------------------------------ |
| `400`      | Origin ヘッダーなし、または リクエストボディ不正 |
| `403`      | 許可されていないオリジンからのリクエスト         |
| `404`      | 存在しないエンドポイント                         |
| `405`      | 許可されていない HTTP メソッド                   |
| `413`      | リクエストボディが 64KB を超過                   |
| `415`      | Content-Type が `application/json` 以外          |
| `500`      | サーバー内部エラー（設定の読み込み失敗等）       |
