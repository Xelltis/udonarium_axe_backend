# Cloudflare版

Cloudflare Workersの上で動く、Axeの**サーバー版**のWorkerです。
部屋のサーバーを受け持ちます。
部屋ごとのDurable Objectが、参加者のやりとりを中継し、卓の状態を持ちます。SkyWayもトークン発行サーバーも使わずに遊ぶためのものです（→ [部屋のサーバー](/cloudflare/rooms)）。
画像と音声は、部屋のアセットとして部屋の中に置き、その部屋の参加者にだけ配ります。

部屋に入るときは、GMとPLはDiscordでログインし、ログインしていない人は見学になります（→ [ログインと役割](/cloudflare/login)）。
部屋のサーバーとログインには、Axe v1.68.0から対応しています（ベータ）。Axeの設定は[Axe側の設定](/guide/client-config#サーバー版で配信するとき)にあります。

## 部屋のアセットのしくみ

画像と音声は、**中身のSHA-256**を名前にして、Cloudflareのファイル置き場（R2）に部屋ごとに置きます。
R2での名前は`rooms/<部屋の鍵>/<SHA-256>`です。
同じ部屋の中なら、何度上げても1つしか置かれません。
部屋が違えば、同じ中身でも別々に置きます。

```text
GMかPL（画像を足した人）
 ├─ HEAD /v1/rooms/<部屋の鍵>/assets/<SHA-256> … 置かれているか確かめる
 └─ PUT  /v1/rooms/<部屋の鍵>/assets/<SHA-256> … 無ければ置く

ほかの参加者
 └─ GET  /v1/rooms/<部屋の鍵>/assets/<SHA-256> … 持っていない画像を受け取る（無ければ部屋のサーバーの中継で頼む）
```

1. GMかPLが部屋の中で画像を足すと、Axeは画像の中身からSHA-256を計算し、その部屋に置かれているかを確かめます。無ければ置きます。部屋に入ったときも、手元の画像と音声のうち、その部屋にまだ無いものを上げます。
2. ほかの参加者は、持っていない画像をまず部屋のアセットから受け取ります。届いた中身のハッシュが名前と合うことも確かめます。
3. 部屋のアセットに無いときや、つながらないときは、持っている人から部屋のサーバーの中継で受け取ります。

どのリクエストにも、部屋のサーバーが席に渡すアセットのトークンが要ります。
トークンには部屋の鍵と席の役割が入っていて、15分で切れます。Axeは切れる前に渡し直してもらいます。
読むのはその部屋の席にいる人ならだれでも（GM・PL・見学）、置くのはGMとPLだけです。
ハッシュや部屋の鍵を知っていても、トークンが無ければ読めません。

部屋のアセットは、部屋と一緒に消します。
GMが部屋を削除したときと、最後の1人が抜けて`ROOM_RETENTION_HOURS`（既定24時間）が過ぎ、部屋を消すときです。
部屋が続いているあいだは消しません。

SkyWay版の配信では、このWorkerを画像と音声の置き場に使えません。
SkyWay版の画像と音声は、P2Pだけで配られます。

## 特徴

- **ハッシュの照合**：PUTの本文のSHA-256が名前と合わなければ置きません。照合はR2が書き込みながら行います。
- **形式の判定**：画像（PNG・JPEG・GIF・BMP・WebP・AVIF・HEIC・SVG）と音声（MP3・WAV・Ogg・FLAC・M4A・AAC）だけを受け付けます。宣言されたContent-Typeではなく、中身の先頭のバイトで判定します。
- **大きさの上限**：画像は2MiB、音声は10MiBまでです（Axeが読み込める上限と同じ）。
- **キャッシュ**：同じデータセンターからの2回目以降のGETは、CloudflareのCache APIから返し、R2を読みません。キャッシュから返すときも、先にトークンを確かめます。
- **部屋と一緒に消す**：部屋を消すときに、その部屋のアセットをすべてR2から消します。置いてからの日数では消しません。
- **レート制限**：送信元ごとに、新しく置くのは1分100件、R2から読むのは1分600件までです。
- **何台でも置ける**：同じCloudflareアカウントに何台置いても、R2のバケット、部屋、レート制限はWorkerごとに分かれます。

## 必要なもの

- Cloudflareのアカウント（無料プランで動きます）
- アカウントでのR2の利用申し込み（アカウントに一度だけ。無料枠があります）
- 本番で使うなら、Cloudflareで管理している独自ドメイン（キャッシュを効かせるため）

部屋のサーバーに使うDurable Objectsは、無料プランでも使えます。
デプロイのときに作られるので、前もって申し込むものはありません。
