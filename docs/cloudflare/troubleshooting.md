# Cloudflare版で困ったとき

よくあるつまずきと、その直しかたをまとめました。
Cloudflare版のエラーは`{"error": "<コード>"}`の形で返るので、まずコードを見てください。

## デプロイでつまずく

Deployボタンや、複製したリポジトリからのデプロイが失敗したときは、Workerの画面の**Deployments**から**View build history**を開き、失敗したビルドのログを見ます。

| 見えるもの                                            | 原因と直しかた                                                                                                                                 |
| ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `Please enable R2 through the Cloudflare Dashboard`   | アカウントでR2を使い始めていない。ダッシュボードの「Storage & databases → R2」で申し込む                                                       |
| バケットを作れない、同じ名前のバケットがある          | 前に同じ名前のWorkerを消したあとなどで、「<Workerの名前>-assets」が残っている。いらなければ消すか、Workerの名前を変える                        |
| `Authentication error`                                | APIトークンの権限が足りない（→ [mainからの自動デプロイ](/cloudflare/auto-deploy#apiトークン)）                                                 |
| Deployボタンの**Create and deploy**を押しても進まない | GitHubに入れた**Cloudflare Workers and Pages**のアプリに、リポジトリを作る権限が無い。GitHubの**Settings**の**Applications**でアプリを入れ直す |
| リポジトリを作れない                                  | 複製先のGitHubのアカウントに、同じ名前のリポジトリがすでにある。リポジトリの名前を変える                                                       |

## エラーのコードから探す

| コード                 | よくある原因                                                                                                                              | 直しかた                                                                                                                                                                                                                                             |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `config-invalid`       | `ACCESS_CONTROL_ALLOW_ORIGIN`か`ROOM_RETENTION_HOURS`が無い、形が違う                                                                     | Workerのログに足りない設定の名前が出る。[設定項目](/cloudflare/configuration)を見直す                                                                                                                                                                |
| `origin-not-allowed`   | Originが許可リストにない                                                                                                                  | `ACCESS_CONTROL_ALLOW_ORIGIN`を、Axeを開いているページのOriginに合わせる。前は通っていたのに急に出るようになったら、複製したリポジトリの`wrangler.jsonc`の値に戻っている（→ [Originの設定を確かめる](/cloudflare/deploy#_8-originの設定を確かめる)） |
| `unsupported-type`     | 受け付けない形式（動画など）                                                                                                              | 正常な動き。その画像は部屋のサーバーの中継で配られる                                                                                                                                                                                                 |
| `too-large`            | 画像が2MiB、音声が10MiBを超えた                                                                                                           | 正常な動き。その画像は部屋のサーバーの中継で配られる                                                                                                                                                                                                 |
| `hash-mismatch`        | 本文のハッシュが名前と合わない                                                                                                            | 正常な動き。Axeはその画像を部屋のサーバーの中継だけで配る                                                                                                                                                                                            |
| `rate-limited`         | 送信元からの上限を超えた                                                                                                                  | 大きな部屋を何度も読み込み直した直後など。少し待てば戻る。Axeは間を置いて試し直す                                                                                                                                                                    |
| `not-found`            | その部屋に置かれていない（部屋が消えて、一緒に消えたときも）。`/v1/account`では、トークンのアカウントがもう無い（別の端末で消したあとも） | 正常な動き。その画像は部屋のサーバーの中継で届く。持っているGMかPLが次に部屋に入れば、また上がる。`/v1/account`では、Axeは消せたものとしてログインを外す                                                                                             |
| `invalid-request`      | 部屋を作る本文がJSONでない、名前が空か長すぎる                                                                                            | 名前は1〜255文字、パスワードは64文字まで                                                                                                                                                                                                             |
| `login-required`       | 部屋を作る・削除する、アカウントを見る・消すのに、ログインしていない（トークンが切れた）                                                  | ログインし直す。Axeはふだん、切れる前にトークンを替える                                                                                                                                                                                              |
| `asset-token-required` | 部屋のアセットのトークンが無い・切れた・ほかの部屋のもの                                                                                  | 部屋に入り直す。Axeはふだん、切れる前に部屋のサーバーに渡し直してもらう                                                                                                                                                                              |
| `not-a-player`         | 見学の席から画像や音声を置こうとした（見学に変えられたあとも含む）                                                                        | 正常な動き。置けるのはGMとPLだけ                                                                                                                                                                                                                     |
| `login-unavailable`    | ログインの3つ（`DISCORD_CLIENT_ID`など）がWorkerに入っていない                                                                            | [ログインを使えるようにする](/cloudflare/login#ログインを使えるようにする)                                                                                                                                                                           |
| `invalid-grant`        | ログインのコードやリフレッシュトークンが、無効・使用済み・期限切れ                                                                        | ログインし直す                                                                                                                                                                                                                                       |
| `blocked`              | 運営する人が、その画像を置かせないようにした                                                                                              | 正常な動き。その画像は使わないでください                                                                                                                                                                                                             |
| `room-not-found`       | その部屋が無い。作られていないか、最後の1人が抜けて時間が過ぎて消えた                                                                     | 部屋を作り直す                                                                                                                                                                                                                                       |
| `room-full`            | 部屋に32人いる、またはWebSocketが64本つながっている                                                                                       | 誰かが抜けるのを待つ                                                                                                                                                                                                                                 |
| `not-game-master`      | 部屋を削除しようとしたが、その部屋のGMでない                                                                                              | 正常な動き。削除はその部屋のGMに頼む                                                                                                                                                                                                                 |
| `upgrade-required`     | 部屋に入るURLを、WebSocketでなく普通のリクエストで開いた                                                                                  | 正常な動き。部屋にはAxeからつなぐ                                                                                                                                                                                                                    |

## 画像が部屋のアセットに上がらない

画像を足した人のブラウザで、開発者ツール（F12）の「ネットワーク」を開き、`/v1/rooms/<部屋の鍵>/assets/`へのリクエストを見ます。

1. **リクエストが飛んでいない。** 部屋に入っていません。Axeは、部屋の外（待機中）では何も上げません。
2. **`HEAD`のあとに`PUT`が無い。** `HEAD`が`200`なら、その部屋にすでに置かれています。正常です。
3. **`PUT`が`403 not-a-player`。** 見学の席からは置けません。置けるのはGMとPLだけです。
4. **`PUT`が`403 origin-not-allowed`。** `ACCESS_CONTROL_ALLOW_ORIGIN`が、Axeを開いているページのOriginと一致していません。
5. **`401 asset-token-required`。** 部屋のアセットのトークンが切れたか、ほかの部屋のものです。部屋に入り直してください。
6. **CORSのエラー。** 4と同じか、Axeの`assets/config.json`の`backend.url`のドメインが間違っています。
7. **`PUT`が`415`や`413`。** 受け付けない形式か大きさです。その画像は部屋のサーバーの中継で配られます。
8. **`PUT`が`404 room-not-found`。** 部屋が削除されたか、保持期間を過ぎて消えています。部屋のアセットのトークンが切れていなくても、もう置けません。

## 画像が部屋のアセットから届かない

ほかの参加者のブラウザで、開発者ツールの「ネットワーク」を見ます。

- **`GET`が`404`。** その部屋にまだ置かれていません。部屋のサーバーの中継で届くので、遊ぶのに困ることはありません。
- **`GET`が`429`。** 送信元からの読み出しが上限を超えています。同じ回線から大勢が参加している（学校や会社のネットワーク、モバイル回線の共有など）と起きやすくなります。[設定項目](/cloudflare/configuration#レート制限を変える)で`READ_LIMITER`の上限を上げます。
- **混在コンテンツ（Mixed Content）のエラー。** Axeが`https://`なのに、`backend.url`が`http://`になっています。

## ログインできない

- **Discordの画面で「Invalid OAuth2 redirect_uri」と出る**：Discordのアプリの**Redirects**に、`https://<Workerのドメイン>/v1/login/discord/callback`が入っていません。`<Workerのドメイン>`は、Axeの`backend.url`に書くのと同じドメインです。`*.workers.dev`で登録したままカスタムドメインから使うと、このエラーになります。
- **Axeに戻ってきたが`login_error=provider-failed`**：`DISCORD_CLIENT_ID`か`DISCORD_CLIENT_SECRET`が、Discordのアプリと合っていません。Client Secretを作り直したときは、Workerのシークレットも入れ直します。
- **ログインを始めると`400 invalid-request`**：戻り先のOriginが`ACCESS_CONTROL_ALLOW_ORIGIN`に名前で書かれていません（`*`は数えません）。
- **すべてのリクエストが`500 config-invalid`**：ログインの3つのうち一部だけが入っているか、`SESSION_SECRET`が32文字より短いです。

## 部屋に入れない・切れる

部屋のサーバーは、接続を閉じる前に理由（コード）を送ります。
コードごとの意味は[部屋のプロトコル](/cloudflare/protocol#接続を閉じる理由)にあります。

- **`protocol-mismatch`**：Axeとサーバーの版が合っていません。Axeを読み込み直して、新しい版にします。それでも直らなければ、Workerが古いままです。新しい版をデプロイしてください。
- **`wrong-password`**：パスワードが違います。部屋を作った人に確かめてください。
- **`replaced`**：同じ人が別のタブや端末から入り直しました。古い方は閉じられます。
- **`bad-message`**：送ったものが読めなかったか、ほかの人のピアIDを名乗りました。見学で入っていた人は、同じピアIDを持つログインした本人が入ってきたときにも、この理由で外れます。
- **`room-deleted`**：部屋のGMが部屋を削除しました。部屋はもう無いので、入るなら作り直してください。
- **`unauthorized`**：アクセストークンが切れたか、無効です。Axeがトークンを替えてつなぎ直します。繰り返すなら、ログインし直してください。見学で入っていた人は、同じユーザーIDでログインした本人が入ってきたときにも、この理由で外れます。つなぎ直しても入れないので、ログインしてから入り直してください。
- **`too-many-messages`**：短いあいだに送りすぎました。ふつうに遊んでいて起きるなら、[Issues](https://github.com/Xelltis/udonarium_axe_backend/issues)で知らせてください。
- **つないですぐ`403`**：Axeを開いているページのOriginが、`ACCESS_CONTROL_ALLOW_ORIGIN`にありません。

## 料金が気になる・遅い

- **`*.workers.dev`のまま使っている。** キャッシュが効かないので、毎回R2から読みます。カスタムドメインを付けてください。
- **リクエストが多すぎる。** Workerのダッシュボードで、どこから多く来ているかを見ます。繰り返し読み出されているなら、カスタムドメインのゾーンにWAFのレート制限ルールを足します（→ [安全のしくみ](/cloudflare/security#workerを呼ぶ回数そのもの)）。

## それでも解決しないとき

[Issues](https://github.com/Xelltis/udonarium_axe_backend/issues)で知らせてください。
エラーのコード、開発者ツールに出たエラー、Workerのログに出たエラーを書いてもらえると助かります。
